#18

결과 = 카드 스택

스캔·미리보기 목록을 얇은 테두리 카드로 통일. max-height 박스 없음 — 패널 body가 스크롤.

CTA

적용 버튼 상단

미리보기·적용·다음을 제목 바로 아래 툴바에. sticky footer·하단 예약 영역 불필요.

설정

기준·오차·깊이 = 설정만

기준 크기 · 허용오차 · 이름 정리 깊이는 설정 탭「기본값」카드에서만. 만들기/적용에는 미노출. 프리셋 기능 제거 — 값은 clientStorage 자동 유지.

토큰

격자 8 고정 · 기준 크기는 설정으로

여백·크기 격자 8px 고정(사다리/정리 UI 없음). 기준 크기(기본 16)는 토큰 단계에서 빼고 설정에서만 변경.

색 → 변수

추출 색을 이 단계에서 변수화

역할 지정 후 색 변수 만들기(Global hue + Semantic 역할). 팔레트 시드: 주색 · 보조색(옵션) · 하모니 유지(현행과 동일). 다음 토큰 단계는 색 외만.

만들기

한 화면 · 한 단계

팔레트→추출→토큰→다크→타이포를 한 스크롤에 다 쌓지 않고, 상단 단계 레일로 전환. 할 일이 한 번에 하나만 보임.

#15

짧은 안내 · 친절한 톤

한 줄 유지하되 명령·내부 메모 톤 완화. 「무엇을 하면 되는지」중심. Free/시드/현행 같은 말 제거.

#17

텍스트 스타일 = 리스트 + ×N

표 열 싸움 대신 이름·요약·개수. 1개면 이동, 여러 개면 전체 선택. 가로 리사이즈에 의존하지 않음.

시작

온보딩 흡수

별도 온보딩 카드를 없애고, 첫 실행 배너만 시작 탭 안에. 준비 현황은 컴팩트 목록.

적용

단계 레일 (만들기와 동일 패턴)

변수 연결 · 이름 정리 · 컴포넌트로 나눔. 한 화면·한 일. 미리보기→선택→적용은 단계 안에서.

연결

건너뜀 사유 칩

HUG/FILL=크기 비고정이라 스킵 · 매칭 없음=변수 없음. 칩 클릭→캔버스에서 해당 레이어 선택(기존 기능).

연결

허용오차 UI 숨김

FLOAT만 해당. 적용 탭 칩 제거. 설정에 0.5px 고정 표시.

#8

내보내기 = 미리보기 없음

형식·단위 → 내보내기 한 번으로 파일 저장(또는 클립보드). 패널 JSON·별도「다운로드」버튼 없음.

변수

편집기 제거 · 흐름으로 대체

CRUD 목록은 Figma Variables. 플러그인은 만들기(upsert)·적용(바인딩)·역할 매핑·내보내기로 “관리”. Tokens Studio식 소스 오브 트루스는 만들기 파이프라인.

제거

명도 대비 점검 삭제

적용 탭·마법사 옵션·진행 단계에서 제외. 결과만 있고 후속이 약한 기능을 빼 흐름을 단순화.
