## 준비

1. 플러그인 폴더를 main 최신으로 맞춘다. `dist/`에 남은 로컬 빌드 잔여물은 이 명령이 되돌린다(`scripts/update.mjs`).

   ```bash
   npm run update -- main
   ```

2. Figma에서 플러그인 창을 닫았다가 다시 실행한다.
3. **새 빌드가 떴는지 먼저 확인**: 선택 탭 › [이름 정리]의 트리 머리 줄이 회색 띠면 최신이다(흰 줄이면 예전 빌드).
4. 만들기 · 컴포넌트 등록은 유료 기능이다. 유료 상태(라이선스 또는 개발용 티어)로 연다.
5. 각 묶음은 **새 복제본**에서 한다. 묶음 3 · 4의 테스트 파일도 Figma에서 복제(⋯ › Duplicate)한 뒤 복제본에서 한다 — 원본은 다시 쓸 수 있게 둔다. 이미 연결 · 등록한 파일은 "이미 연결됨"으로 건너뛰어 아무것도 바뀌지 않는다.

**지금 화면에서 쓰는 경로**
- 만들기: 선택 탭 › 할 일 [변수 만들기] → 만들기 화면(탭 Global · Semantic · Text Style) → 아래 [변수 만들기]
- 연결: 선택 탭 › 카드 1 "변수 없는 값 {n}곳" [{m}곳 연결](연결할 곳 수 — 제목 수와 다를 수 있다) → 연결 화면 → 아래 [{o}곳 연결]
- 컴포넌트: 선택 탭 › 할 일 [컴포넌트 베타] → 컴포넌트 화면 → [등록]
- 변수 상세: 변수 탭 › 변수 우클릭 › 상세…

결과 칸: ✅ 합격 · ❌ 불합격(무엇이 달랐는지 한 줄 + 스크린샷) · ⏸ 못 함(이유).
