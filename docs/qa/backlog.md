# QA 대기 목록

지금 고치지 않고 다음 QA 때 확인·처리할 항목. 처리하면 해당 QA 기록으로 옮기고 여기서 지운다.

- **되돌리기 뒤 카드 갱신**(2026-11-17 실기 묶음 1): 연결 직후 ⌘Z로 연결이 모두 풀려도 선택 탭 카드가 "✓ 연결할 곳은 모두 연결됐어요"로 남음. 선택을 바꿔야 다시 셈. ⌘⇧Z로는 연결이 되살아나지 않음(피그마 동작인지 확인 필요).
- **만들기에서 이름이 바뀜**(2026-11-17 실기 묶음 1): [이름 정리]를 누르지 않았는데 기본 이름 65 → 0. 만들기 · 연결이 이름 정리를 함께 하는 것이 명세(ia-v4 §4.3 · §4.4)와 맞는지 확인.
- **복제 표시 낱말이 접두사가 됨**(2026-11-17 QA #5): 프레임 "원본-copy" → 이름 정리 접두사 `copy-`(한글 "원본"은 빠짐) → 컴포넌트 `CopyImage` · `CopyButton`. `copy` · `복사본` 같은 낱말을 접두사에서 뺄지, 한글 낱말을 어떻게 다룰지 확인.
- 결과 줄 꼬리 · 처리 중 문제의 멤버 이름이 같으면(예: `list-article` ×3) 어느 멤버인지 구분되지 않는다 — 순번이나 위치를 붙이는 안 (QA #5 재실기 3, 2026-11-17)
- **[등록] 뒤 레이어 수가 늘어남**(2026-11-18 주요 흐름 실기, QA #5부터): `Flightin website (DSL 실기)` 255 → 270 — 안쪽 사진 · 아바타 · 아이콘을 감싸는 `ArticleImage` · `Avatar` · `Icon` 인스턴스 감싸개가 4개씩 생김. 감싸지 않고 담을 수 있는지 확인.
- **이름이 약한 컴포넌트 `Wrapper` · `Wrapper2` · `Wrapper3`**(2026-11-18 주요 흐름 실기): 이름 정리가 역할을 찾지 못한 레이어(`wrapper`)가 그대로 컴포넌트가 되고 숫자만 붙음 — Components 페이지에서 무엇인지 알 수 없다. 부모 역할(예: `Article-Type1` 안)을 이름에 쓰거나 후보에서 빼는 안.
- **글자 크기 Semantic이 굵기 · 자간 표시로 쪼개짐**(2026-11-18 주요 흐름 실기 1단계): `font-size/18` 하나를 가리키는 Semantic 11개(`font-size/body/large-120-ls0_4` · `font-size/label/large-w600-125` 등) — 텍스트 스타일 이름의 줄 높이 · 굵기 · 자간 꼬리가 글자 크기 변수 이름에 남음. 크기 변수는 크기만 다를 때만 나누는 안.
- **회색 계열 이름의 유채색**(2026-11-18 주요 흐름 실기 1단계): `color/gray/50-2` = #F4F9FA(옅은 청록) — 회색 단계 이름에 `-2`가 붙음. 색 분류(`classifyColor`)의 무채색 기준 확인.
- **격자(GRID) 배치의 간격은 연결하지 않음**(2026-11-18 주요 흐름 실기 1단계): `circulars` · `points`(GRID, 간격 10)는 `spacing/10`이 있는데 연결 안 됨. 의도(격자 간격은 다른 속성)인지 코드로 확인.
