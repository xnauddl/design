## §1 불합격 1 — 글자 칠하기 용도 불일치 (수정)

- 현상: 흰 글자 6개 — `Contact` · `Business Class` · `01` · `02` · `03` · `Subscribe Now` — 의 `fills`가 Semantic `color/background/default`(용도 `FRAME_FILL | SHAPE_FILL`)에 연결됨. 글자에는 `TEXT_FILL`(또는 `ALL_FILLS`)이 필요하다. 이대로면 배경 역할 값을 바꿀 때 버튼 글자색이 같이 바뀐다.
- 원인(코드 확인): `src/lib/scopes.ts`
  `FILL_SCOPES = ['ALL_FILLS', 'FRAME_FILL', 'SHAPE_FILL', 'TEXT_FILL']` — `bind.ts:530 const allowed = key === 'fills' ? FILL_SCOPES : STROKE_SCOPES;` 가 노드 종류를 보지 않는다. `matchColor`는 `colorScopeOk(e, allowed)`로 이 4개 중 하나만 맞으면 통과시키므로 TEXT의 #FFFFFF가 FRAME_FILL 전용 변수와 매칭된다. Semantic이 Global보다 먼저 오므로 `color/gray/0`(ALL_FILLS)이 아니라 역할이 잡힌다.
- 수정 스펙(예상 30분):
  1. `scopes.ts`: `fillScopesFor(nodeType)` — TEXT → `['ALL_FILLS','TEXT_FILL']`, FRAME · COMPONENT · COMPONENT_SET · INSTANCE · SECTION → `['ALL_FILLS','FRAME_FILL']`, 그 밖(RECTANGLE · ELLIPSE · VECTOR · POLYGON · STAR · LINE · BOOLEAN_OPERATION) → `['ALL_FILLS','SHAPE_FILL']`. `ALL_SCOPES`는 지금처럼 통과.
  2. `bind.ts:530`: `allowed = key === 'fills' ? fillScopesFor(node.type) : STROKE_SCOPES`. 연결 직전 다시 확인에도 같은 함수.
  3. 변수 탭(§4.4) 사용 표시·찾기 미리보기도 같은 판정을 쓰는지 확인(다른 곳에 `FILL_SCOPES`를 직접 쓰는 데가 있으면 교체).
  4. 테스트 `test/figma.test.mjs`: 흰 TEXT 1개 + 변수 2개(`color/background/default`[FRAME_FILL,SHAPE_FILL] Semantic, `color/gray/0`[ALL_FILLS] Global) → TEXT는 `gray/0`에, 같은 색 FRAME은 `background/default`에 연결. TEXT_FILL 전용 변수는 FRAME에 안 붙음.
  5. 명세 §2.11 "색"에 한 줄: "칠하기 용도는 레이어 종류를 따른다 — 글자 TEXT_FILL · 프레임 FRAME_FILL · 도형 SHAPE_FILL(ALL_FILLS는 전부)".
- 기대 결과: 재실행 시 이 6개 글자는 `color/gray/0`(Global)에 연결(10/28 QA #1 상태와 같음). 사용자가 글자용 흰색 역할(`color/text/inverse`)을 지정하면 그쪽에 붙음. 나머지 608건 변화 없음.
