## 불합격 1 — `header-logo` 오탐 (수정 요청)
현상(결과 프레임 헤더):
```
website-header
  container
    header-logo (9점 그리드)      ← 맞음
    container
      header-logo  "Support"      ← ✗
      container
        header-logo + "Language"  ← ✗
    header-actions
```
원인: `src/lib/rename.ts` `isLogoLike()`가 "헤더 맥락 + 부모 안 첫 자리(pos.index===0) + 작음"만 보고, 헤더에서 몇 단계 아래인지 안 봄 → 중첩 컨테이너의 첫 자식마다 logo.

수정 스펙:
1. `recurse()`에 `ctxDepth: number` 추가. 규칙: 맥락(ancestorName)을 새로 정한 노드(passthrough 아님)의 자식 = 0, passthrough(container/wrapper) 노드의 자식 = 부모 ctxDepth + 1. `Pos`에 `ctxDepth` 필드로 전달.
2. `isLogoLike`·`isActionsLike`에 `pos.ctxDepth <= 1` 조건 추가(header > logo, header > row > logo 까지만). `isNavLike`는 그대로.
3. 반드시 **이름이 아니라 ctx 체인**으로 셀 것 — 미리보기(apply=false)에서는 부모 이름이 아직 안 바뀌어 있어 `node.parent.name`을 보면 미리보기와 적용 결과가 달라진다.
4. 테스트: `test/figma.test.mjs` "헤더 안 logo/nav/actions + 본문 첫 블록 hero" 테스트에 중첩 케이스 추가 — `header > row > container(H) > wrapper("Support")`는 `container`/`wrapper`로 남아야 함(현재 기대값 `header-logo`(그리드)·`header-actions`는 유지). 예상 30분.
