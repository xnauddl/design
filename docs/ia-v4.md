# IA v4 — 선택 탭 · 변수 탭 · ⚙ (2026-11-09 사용자 확정)

> 시안 9장(2026-11-09 확정): ① 선택 탭 ② 쓰는 변수 펼침 ③ 선택 없음 ④ 변수 없는 파일 ⑤ 변수 탭 ⑥ 변수 탭 ＋ 메뉴 ⑦ 연결 화면 ⑧ 변수 만들기 ⑨ 이름 정리.
> 이 문서는 ia-v3의 **화면 구조**(§3 · §4 · §5 · §6 · §7)를 바꾼다. ia-v3의 원칙 중 아래 §2.2에 적은 것은 그대로 쓰고, 여기서 다르게 적은 것만 바뀐다. 둘이 다르면 이 문서를 따른다.

## 0. 결정 요약

| 항목 | 결정 |
|---|---|
| 탭 | **[선택] [변수]** 두 개 + ⚙(설정) + —(최소화). 레이어 탭 · 설정 탭은 없앤다 |
| 탭 규칙 | **선택 탭 = 지금 선택한 레이어에서 할 일, 변수 탭 = 파일의 변수** |
| 선택 탭 첫 화면 | 선택 이름 + 카드 최대 3장(변수 없는 값 · 쓰는 변수 · 삭제된 변수) + 맨 아래 "레이어 정리"(이름 정리 · 컴포넌트) |
| 연결 | 카드 [n곳 연결] → 연결 화면 하나(찾기 · 고르기 · 연결 3단계를 합침). 찾기는 선택이 바뀌면 자동(300개 규칙) |
| 만들기 | 화면 하나(종류 체크 + "만든 뒤" 옵션) — 만들기 6단계와 "한 번에 정리" 마법사를 합침. 자세한 화면은 [값을 직접 고르기 →] |
| 변수 탭 | 사이드바 = 컬렉션만. 오른쪽 = 그룹 머리 → Global은 값 알약 · 색 동그라미, 그 밖은 줄(이름 · 가리키는 변수). 사용 수 · 사용 표시 없음 |
| 변수 클릭 | **지금 선택에 연결**(이미 붙은 것도 바꿈, Global도 — 사용자가 직접 고른 경우의 예외, §2.3) |
| 우클릭 | 다른 곳에 연결 ▸ · 상세… · 복제 · 삭제 (라이브러리 변수는 상세…만) |
| 상세 | "상세"와 "고치기…"를 하나로. 이름 복사 · CSS 복사 · 가리키는 변수로 → · 쓰인 곳 {n}곳 · [모두 선택] |
| 간접 사용 | 표시하지 않는다(↳ 없앰, Global의 사용 표시 없음, 상세의 간접 줄 없음) |
| 변수 추가 · 복제 | 무료, 단 개수 제한(숫자 · 기준은 추후 결정 — §9) |
| 삭제 | 무료, 확인 창 늘 띄움(라이브러리 게시 경고는 넣지 않음) |
| 설정 | ⚙ → 설정 화면(기본값 · 라이선스) |

## 1. 왜 바꾸나

- 사용자가 하는 일은 셋이다: ① 선택한 디자인을 변수에 **연결** ② 변수가 없으면 **만들기** ③ 변수 **보기 · 고치기**. 가끔 하는 일로 레이어 정리(이름 · 컴포넌트)와 설정이 있다.
- v3에서는 ①이 세 곳(레이어 › 연결, 변수 탭 ★ Inspect · LIB · 삭제된 변수, 머리줄 링크)에, ②가 여섯 단계 + 마법사에 나뉘어 20개 넘는 기능이 8곳에 흩어졌다. 가끔 쓰는 기능도 탭 하나씩을 차지했다.
- v4는 "지금 선택에서 할 일"을 한 화면(선택 탭)에, "파일의 변수"를 한 화면(변수 탭)에 모은다.

## 2. 원칙

### 2.1 탭과 머리
- 머리: [선택 | 변수](세그먼트, 남는 폭) + ⚙(32×32, 툴팁 "설정") + —(최소화, v3 그대로).
- 창을 열면 **선택 탭**이다(v3는 변수 탭). 고른 탭은 세션 동안 기억한다.
- 하위 화면(연결 · 만들기 · 이름 정리 · 컴포넌트 · 설정)은 탭 안에서 "← 제목" 머리로 들어가고, ←(또는 Esc — 입력 칸 · 팝업이 없을 때)로 돌아온다. 하위 화면에 있는 동안 탭을 바꿨다 돌아오면 그 하위 화면이 그대로 있다(v3 §2.6 하위 화면 기억).

### 2.2 ia-v3에서 그대로 쓰는 것
- 창 480 × 510 · 최소화 140 × 104(v3 §0 · A.11), 공통 상태 줄(v3 §2.3 · §3.x), 잠금 표시와 사유(v3 §2.3), 상태 기억(§2.6), `nodechange` 안 씀(§2.7), 라이트 고정(§2.8), 접근성(§2.10), 다시 읽기 규칙(v3 "다시 읽기" — 바뀐 점은 §7).
- **연결 원칙(v3 §2.11)** · **역할(§2.12)** · **플러그인 컬렉션(§2.13)**은 자동 연결(연결 화면)과 만들기에 그대로 적용한다. 예외는 §2.3 하나다.
- 상세 팝업의 고치기 규칙(v3 §4.4 "고치기" — 칸 · 저장 · 오류 · 닫기 확인)은 그대로, 더하는 것만 §4.8.

### 2.3 클릭 연결 예외 (2026-11-09 사용자 결정)
- 사용자가 변수 탭에서 변수를 **직접 클릭**하거나 "다른 곳에 연결"을 고르면 지금 캔버스 선택에 붙인다.
  - 값이 달라도 붙인다(레이어 모습이 변수 값으로 바뀐다).
  - 이미 다른 변수가 붙어 있어도 바꾼다.
  - Global도 붙인다.
  - 인스턴스 안쪽 레이어를 선택했어도 붙인다(피그마의 오버라이드가 된다).
- v3 §2.11의 "이미 붙은 것은 바꾸지 않는다 · 값이 같은 곳만 · 인스턴스 안쪽은 건드리지 않는다 · 붙이는 일은 [연결]과 [기존 스타일 연결]뿐", §2.12 "레이어에는 Semantic만"은 **연결 화면(자동 연결)에만** 적용된다.

### 2.4 용어
- 레이어에 변수를 붙이는 일은 어디서든 **"연결"**이라고 부른다(v3 §2.9). "적용"이라는 말은 쓰지 않는다.
- 플러그인 안 이동은 "→", 밖으로 나가는 링크만 "↗"(v3 §2.9).

### 2.5 목록 기준 (선택 탭)
- 선택 탭의 카드 · 목록은 **목록 기준**(v3 ③)의 레이어로 계산한다. 사용자가 캔버스에서 선택을 바꾸면 기준이 그 선택으로 바뀐다.
- 플러그인이 만든 선택(상세 [모두 선택], 삭제된 변수 [선택], 연결 직후 피그마가 보내는 선택)은 기준을 바꾸지 않는다. 그동안 선택 이름 줄에 "지금 선택과 달라요 · [기준 바꾸기]"가 붙는다.
- 변수 탭의 클릭 연결은 기준이 아니라 **지금 캔버스 선택**에 한다(플러그인이 만든 선택이어도). 연결 결과 문구의 "레이어 n개"가 그 수다.

## 3. 구조

```
플러그인 (480 × 510 · 최소화 140 × 104)
├─ 머리: [선택 | 변수] ⚙ —
├─ 선택 탭 (기본)
│   ├─ 첫 화면: 선택 이름 · 카드(변수 없는 값 / 쓰는 변수 / 삭제된 변수) · 레이어 정리
│   ├─ ← 연결 화면 (⑦)
│   ├─ ← 변수 만들기 (⑧) ─ ← 값을 직접 고르기(색 · 토큰 · 다크 · 텍스트 스타일 — v3 만들기 화면)
│   ├─ ← 이름 정리 (⑨)
│   └─ ← 컴포넌트 (베타, v3 레이어 › 컴포넌트 내용)
├─ 변수 탭
│   ├─ 머리 줄: 🔍 검색 · 모드 ▾ · ＋ · ⋯
│   ├─ 사이드바(컬렉션) │ 오른쪽(그룹 → 알약 · 동그라미 · 줄)
│   └─ 팝업: 상세 · 새 변수 · 삭제 확인 · 내보내기 · 준비 현황(팝오버)
└─ ⚙ 설정 화면: 기본값 · 라이선스
```

## 4. 화면

### 4.1 선택 탭 — 첫 화면

**머리 줄**(높이 32): 선택 이름(굵게, 200px 말줄임) + "레이어 {n}개"(`--text-2`). 여러 개를 골랐으면 "{첫 이름} 외 {k}개 · 레이어 {n}개". 목록 기준이 지금 선택과 다르면 오른쪽에 "지금 선택과 달라요 · [기준 바꾸기]"(§2.5).

**상태별 본문**

| 상태 | 본문 |
|---|---|
| 첫 정보 전 | "불러오는 중…" |
| 선택 없음 (③) | 가운데 "디자인에서 레이어를 선택하세요" 한 줄. 아래 레이어 정리 버튼은 `aria-disabled`(사유 "선택이 없어요") |
| 큰 선택(목록 기준 노드 300개 초과), 아직 안 읽음 | "선택이 커서 자동으로 읽지 않아요 · [읽기]" 한 줄 |
| 읽는 중 | 카드 자리에 "선택을 읽는 중…" |
| 로컬 변수 0개 (④) | 카드 하나: "이 파일엔 아직 변수가 없어요" + 둘째 줄 종류별 수("색 9 · 간격 6 · 반경 3", 추출 결과) + [변수 만들기](무료면 잠금 — §6) |
| 로컬 변수 0개 + 선택이 라이브러리 변수를 씀 | 카드 하나: "라이브러리 변수만 써요 · 연결은 피그마 오른쪽 패널에서 해요"(버튼 없음) + 그 아래 쓰는 변수 카드(라이브러리만) |
| 그 밖 (①) | 아래 카드들 |

**카드 1 — 변수 없는 값**
- 목록 기준이 바뀌면 400ms 뒤 **찾기를 자동으로** 돌린다(v3의 [찾기] 버튼은 없앤다). 300개를 넘으면 위 표의 [읽기]로만.
- 제목 "변수 없는 값 {n}곳", 둘째 줄 종류별 수(간격 · 반경 · 크기 · 선 두께 · 색 · 글자 · 텍스트 스타일 순, 0은 뺌). 버튼 **[{m}곳 연결]**(주 버튼, m = 연결할 수 있는 곳 — 매칭 없음은 뺌) → 연결 화면(§4.2).
- 연결할 수 있는 곳이 0이고 매칭 없음만 있으면: 버튼 대신 [변수 만들기 →](→ §4.3).
- 매칭 없음이 있으면 둘째 줄 끝에 " · 변수가 없는 값 {k}곳 [만들기 →]".
- 변수 없는 값이 0이면 카드를 `--ok-subtle` 바탕 "✓ 모든 값이 변수에 연결돼 있어요"로 바꾸고 버튼은 없다.
- 계층 컬렉션에 변수가 없으면(v3 §4.6 `bind.noTier`) 버튼 자리에 [변수 만들기].

**카드 2 — 쓰는 변수**
- 제목 "쓰는 변수 {n}개", 둘째 줄 계층별 수("Semantic 5 · Component 1 · 라이브러리 1"). 오른쪽 [보기 ▾] / [접기 ▴](펼침은 세션 동안 기억).
- n = 목록 기준 레이어(인스턴스 안쪽 포함, 숨긴 레이어 제외 — v3 쓰는 변수 판정)에 **직접 연결된** 변수 수. 간접(별칭이 가리키는 변수)은 세지도 보이지도 않는다(2026-11-09 사용자 결정).
- 펼치면(②) 카드 아래에 목록: 경로 머리("S Semantic › color/text", 라이브러리는 "라이브러리 › {컬렉션}") + 줄(끝 이름 · 값 알약 · "{n}곳"). 순서는 계층(Component → Semantic → Global → 계층 없음 → 라이브러리) → 그룹 → 피그마 순서.
- 줄 클릭 · Enter = 상세…(§4.8). 우클릭 메뉴는 "상세…" 하나. 줄 안의 알약도 상세를 연다.
- 0개면 카드를 보이지 않는다.

**카드 3 — 삭제된 변수** (자리가 있을 때만)
- `--danger` 글자 "삭제된 변수 {n}곳" + [선택](그 레이어들을 캔버스에서 선택 — 기준은 유지).

**레이어 정리**(맨 아래 고정, 구분선 위): "레이어 정리" + [이름 정리] → §4.4, [컴포넌트 베타] → §4.5. 선택이 없으면 `aria-disabled`.

**스크롤:** 머리 줄은 고정, 카드 영역은 패널 스크롤, 레이어 정리 줄은 아래 고정.

### 4.2 연결 화면 (⑦)

- 머리: "← {선택 이름}" + 오른쪽 "변수 없는 값 {n}곳".
- 내용은 카드 1의 찾기 결과(v3 §4.6의 `APPLY_RESULT` preview, 결과 상한 없음 — v3 "찾기 · 연결의 수")를 **변수별 줄**로 보인다.
  - 종류별 머리("색 9곳"), 그 아래 줄: [견본] 값 → 붙을 변수 이름(+ 새 역할이면 N 배지, 툴팁 "{Global 이름}을 가리켜요" — v3 §4.6) · "{n}곳" · 스위치.
  - 스위치를 끄면 그 줄의 곳은 빠지고 아래 버튼 숫자가 바뀐다. 모든 줄을 끄면 버튼은 `aria-disabled`(사유 "연결할 곳을 켜 주세요").
  - 텍스트 스타일(로컬 텍스트 스타일과 값이 같은 글자 — v3 [기존 스타일 연결])은 "텍스트 스타일" 머리 아래 같은 모양의 줄로(이름 → 스타일 이름).
  - 줄이 200개를 넘으면 v3 §4.6처럼 그리기만 줄이고 "외 {n}곳"(누르면 그 레이어 선택).
- [건너뜀 {m} ▸] 칩: 누르면 사유 칩이 펼쳐진다(v3 사유 그대로).
- 아래 고정: [{n}곳 연결](주 버튼). 연결 직전 다시 확인(v3 그대로) → 끝나면 첫 화면으로 돌아오고 상태 줄 "🔗 {n}곳 연결 · ⌘Z로 되돌리기"(건너뛴 곳이 있으면 " · 건너뜀 {m}"). 카드는 다시 읽는다.
- 없애는 것(v3 §4.6): 단계 표시(찾기 · 고르기 · 연결), [찾기] · [다시 찾기], 필터 칸, 속성 아이콘, 줄의 레이어 펼치기, 연결 후 결과 카드.

### 4.3 변수 만들기 (⑧)

- 머리: "← 변수 만들기" + 오른쪽 "{선택 이름}에서 찾은 값".
- 들어오면 목록 기준을 추출한다(v3 `EXTRACT`, 무료).
- **종류 줄**(색 · 간격 · 반경 · 크기 · 선 두께 · 글자, 값이 있는 것만): 체크 + 종류 이름 + 개수 + 미리보기(색 16px 동그라미, 숫자 알약, 최대 12개 + "+n"). 기본은 글자만 끄고 모두 켬.
- **만든 뒤**:
  - [✓] 바로 레이어에 연결(기본 켬) — 만든 다음 자동 연결(연결 화면 없이 바로, v3 §2.11 원칙)
  - [ ] 레이어 이름도 정리(무료)
  - [ ] 다크 모드도 만들기(유료, 무료면 잠금 + 사유)
- [값을 직접 고르기 →]: v3 변수 › 만들기 화면(색 · 팔레트 / 간격 · 크기 토큰 / 시맨틱 매핑 / 다크 / 텍스트 스타일)을 하위 화면으로 연다. 내용은 v3 그대로, 머리만 "← 값을 직접 고르기".
- 아래 고정: 만들 수("Global {g}개 · 역할 {r}개", v3 미리보기 `previewCreateTokens` · `createUsageRoles(preview)`) + [변수 만들기](유료 — §6).
- 실행은 v3 마법사의 단계를 그대로 잇는다(만들기 → 연결 → 이름 정리 → 다크). 진행 중에는 버튼이 "만드는 중… {단계}"로 바뀌고 다른 쓰기 버튼은 잠긴다(v3 공통 잠금). 끝나면 첫 화면으로 돌아오고 상태 줄에 요약("변수 {g}개 · 역할 {r}개 · {n}곳 연결").
- 선택이 없으면 이 화면에 들어올 수 없다(들어와 있는 중 선택이 풀리면 "디자인에서 레이어를 선택하세요"와 [← 돌아가기]).

### 4.4 이름 정리 (⑨)

- 머리: "← 이름 정리" + 오른쪽 "{선택 이름} · 바꿀 이름 {n}개".
- 줄: 체크 + 옛 이름(취소선, `--text-2`) → 새 이름(굵게). 기본 모두 켬. 규칙은 v3 이름 정리 그대로(최상위 · 인스턴스 이름은 그대로 — 안내 문구는 두지 않는다).
- 맨 위 체크 "잠긴 레이어 빼기"(v3 `rename.hideKeep`, 기본 켬).
- 아래 고정: [{k}개 이름 바꾸기](k = 켠 수, 0이면 잠금). 끝나면 첫 화면 + 상태 줄 "이름 {k}개 바꿈 · ⌘Z로 되돌리기".

### 4.5 컴포넌트 (베타)

- 머리: "← 컴포넌트 베타". 내용은 v3 레이어 › 컴포넌트 그대로(후보 등록 · 닮은 프레임 묶기 · 분류 · 빠진 변형, 유료 잠금 그대로).

### 4.6 변수 탭

**머리 줄**(고정): [🔍 변수 검색](남는 폭) · [모드 ▾](보이는 모드가 1개면 숨김) · [＋] · [⋯].
- 검색: 입력하면 모든 로컬 컬렉션에서 전체 경로 부분 일치(대소문자 무시). 결과는 오른쪽에 경로 머리로 묶고 사이드바 고른 표시는 흐리게. 결과 없음 "'{q}'와 맞는 변수가 없어요 · [검색 지우기]". 라이브러리 변수는 찾지 않는다.
- [＋] 메뉴(⑥): 새 변수(§4.9 — 지금 컬렉션에) · (구분선) · 선택에서 변수 만들기… · 다크 모드 만들기… · 텍스트 스타일 만들기… — 아래 셋은 선택 탭으로 바꾸고 §4.3(또는 그 "값을 직접 고르기"의 해당 화면)을 연다. 선택이 없으면 셋은 `aria-disabled`("선택이 없어요").
- [⋯] 메뉴: 준비 현황 {k}/7…(팝오버 — v3 그대로) · 코드로 내보내기…(팝업 — v3 그대로) · (구분선) · 색 격자로 보기 / 색 목록으로 보기(전환, 기억) · 그룹 모두 펼치기 · 그룹 모두 접기.

**사이드바**(128px): 로컬 컬렉션만. 계층 배지(G · S · C · –, 배지 툴팁은 v3 §4.4 그대로) + 이름(말줄임) + 전체 변수 수. 순서 Component → Semantic → Global → 계층 없음, 같은 계층은 피그마 순서. 처음에는 첫 컬렉션, 그 뒤 마지막으로 고른 컬렉션을 기억. 그룹 · ★ Inspect · LIB · 삭제된 변수 항목은 없다.

**오른쪽 목록**
- 그룹 머리(24px, [▾/▸] + 경로 = 이름의 마지막 "/" 앞, 접기 기억)만 있다. "/"가 없는 변수는 맨 위에 머리 없이.
- 그룹 순서는 **종류 순서**(간격 → 반경 → 크기 → 선 두께 → 투명도 → 색 → 글자 → 기타), 같은 종류 안에서는 피그마 순서. 그룹 안 변수도 피그마 순서.
- **종류 판정**(타입이 먼저): COLOR → 색. BOOLEAN → 기타. FLOAT · STRING은 이름 첫 마디(소문자로 비교)로 — FLOAT이고 `spacing` → 간격, `radius` → 반경, `size` → 크기, `stroke-width` → 선 두께, `opacity` → 투명도, `font-size` · `line-height` · `letter-spacing` → 글자; STRING이고 `font-family` → 글자; 그 밖은 기타. 그룹의 종류는 그 그룹 첫 변수의 종류.
- **Global 계층 컬렉션:**
  - 숫자 · 글자 변수 → 값 알약(높이 24, 좌우 8, 줄바꿈, 간격 4). 글자는 고른 모드의 값(숫자 소수 둘째 자리, 글자 120px 말줄임). 그 모드의 값이 별칭이면 "→ {대상 끝 이름}".
  - 색 변수 → 동그라미. 목록 보기(기본): 18px 동그라미 + 끝 이름(높이 28). 격자 보기: 24px 동그라미만(간격 7).
  - 툴팁(마우스 · 키보드 포커스 모두): 전체 이름 / 값.
  - 사용 표시는 없다(2026-11-09 사용자 결정 — 사용은 선택 탭에서 본다).
- **Semantic · Component · 계층 아님 컬렉션:** 줄(이름 = 끝 이름 · 값 알약). 열 폭: 이름 남는 폭, 값 180px. 사용 수 칸 없음.
- 로컬 컬렉션이 0개면 오른쪽 전체에 "아직 변수가 없어요 · [선택에서 변수 만들기]"(선택이 없으면 버튼 `aria-disabled`).

**조작** (알약 · 동그라미 · 줄 공통)

| 조작 | 결과 |
|---|---|
| 클릭 | 지금 캔버스 선택에 **연결**(§4.7). 선택이 없으면 연결하지 않고 상태 줄 `status.noSelection`("선택이 없어요 — 캔버스에서 레이어를 선택하세요") |
| 더블클릭 | 클릭과 같다. 두 번째 click(`event.detail > 1`)은 버린다 — 연결은 한 번 |
| Enter | 상세…(§4.8) |
| Space | 연결(클릭과 같음) |
| 우클릭 · Shift+F10 · 컨텍스트 메뉴 키 | 메뉴: 다른 곳에 연결 ▸ · 상세… · 복제 · (구분선) 삭제 |
- 연결이 진행 중이면 다른 클릭은 무시한다(상태 줄 "연결하는 중…").
- 줄 안의 별칭 알약도 클릭 = 연결이다. 가리키는 변수로 가기는 상세의 [→]로.
- 줄 고르기(파란 바탕) 상태는 없다. 키보드 포커스 표시만.

**키보드** (사이드바 `tree` · 오른쪽 `grid`, 각각 정지점 1개 — v3 그대로)
- 오른쪽: ↑ ↓ = 줄(그룹 머리 · 줄 · 알약 줄 · 동그라미 줄) 사이, 알약 · 동그라미 줄로 들어가면 같은 열에 가까운 것. ← → = 알약 · 동그라미 줄 안. 그룹 머리에서 Enter · Space = 접기 · 펼치기. Home / End · PageUp / PageDown = v3 그대로. Esc = 메뉴 · 팝업 닫기, 검색 지우기.
- 알약 · 동그라미에 포커스가 오면 툴팁 내용을 띄운다. 접근성 이름 "{전체 이름}, {값}".
- 포커스 순서: 탭 → ⚙ → — → 머리 줄(검색 · 모드 · ＋ · ⋯) → 사이드바 → 오른쪽.

### 4.7 클릭 연결 규칙

- **대상:** 지금 캔버스 선택의 레이어 각각(선택한 레이어만, 자식은 아님). 숨긴 · 잠긴 레이어도 선택돼 있으면 한다.
- **속성 고르기 순서:** ① 변수 용도(scopes)가 허용하는 속성만 후보 ② 그중 아래 기본 속성 ③ 그 레이어에 그 속성이 없으면 건너뜀(이유를 센다).

| 종류 | 기본 속성 |
|---|---|
| 색 | 용도가 STROKE_COLOR만이면 선 색, EFFECT_COLOR만이면 그림자 색. 그 밖: 글자 레이어 → 글자 색, 그 밖 → 채움 |
| 간격 | 이름 끝 마디(v3 §2.12 12.3 이름 표의 역): `gap` → 간격(`itemSpacing`), `row-gap` → 줄 간격(줄바꿈이면 `counterAxisSpacing`, 아니면 `itemSpacing`), `column-gap` → `itemSpacing`, `padding` → 안쪽 여백 4방향, `padding-x` → 좌 · 우, `padding-y` → 위 · 아래, `padding-top · -right · -bottom · -left` → 그 방향. 그 밖(예 `spacing/16`) → 간격 |
| 반경 | 끝 마디가 `-top-left` 등이면 그 모서리, 그 밖은 모서리 4곳(`topLeftRadius` … 필드가 있는 레이어만) |
| 크기 | 가로 · 세로 |
| 선 두께 | 끝 마디가 `-top` 등이면 그 방향, 그 밖은 `strokeWeight` |
| 투명도 | 레이어 투명도(`opacity`) |
| 글자 | 그 글자 속성(fontSize · lineHeight · letterSpacing · fontFamily) |
| 기타 | 붙이지 않는다 — 상태 줄 "이 변수는 붙일 속성을 정할 수 없어요" |

- **색 세부:**
  - 채움 · 글자 색: 보이는 단색 채움 중 **맨 위**(fills 배열의 마지막)에 붙인다. 단색 채움이 없으면(그라디언트 · 이미지만, 또는 없음) 맨 위에 단색 채움을 새로 만들어 붙인다. 채움이 없는 노드(그룹 · 슬라이스)는 건너뜀.
  - 글자 색이 구간마다 다르면 글자 전체를 단색 하나로 바꾼다.
  - 색 스타일이 붙어 있으면 스타일 연결이 끊긴다(사용자가 직접 고른 것 — 받아들임).
  - 투명도가 있는 색 변수도 붙인다(페인트 불투명도가 변수 값을 따른다).
  - 선 색: 보이는 선이 없으면 1px 안쪽 단색 선을 만든다. 그림자 색: 그림자가 없으면 건너뜀.
- **숫자 세부:**
  - 간격 · 여백은 오토 레이아웃(가로 · 세로)인 레이어만. GRID 레이아웃 · 오토 레이아웃 아님은 건너뜀. "공간 분배(Space between)"인 레이어에 간격을 붙이면 피그마가 정렬을 바꾼다 — 받아들인다.
  - 크기: HUG · FILL 축은 FIXED가 된다 — 받아들인다. 글자 · 그룹은 건너뜀.
  - 반경: `topLeftRadius` 필드가 없는 레이어(원 · 다각형 · 별 · 벡터 · 글자)는 건너뜀.
  - 선 두께: 보이는 선이 없으면 건너뜀.
- **글자 세부:** 글자의 모든 구간 글꼴을 불러온 뒤 붙인다. 글꼴 이름(font-family)을 바꿀 때 같은 스타일이 그 글꼴에 없으면 그 레이어는 건너뜀. 줄 높이 · 자간은 px 값이 된다. 텍스트 스타일이 붙어 있으면 스타일 연결이 끊긴다(받아들임). 빈 글자는 건너뜀.
- 결과(상태 줄, ⌘Z 한 번): "레이어 {n}개에 {이름} 연결" + 건너뛴 것이 있으면 " · {m}개는 맞지 않아 건너뜀" + " · ⌘Z로 되돌리기". 하나도 못 붙였으면 "선택한 레이어에 {이름}을 붙일 곳이 없어요".
- 연결 뒤 선택 탭 데이터를 다시 읽는다(§7).
- **다른 곳에 연결 ▸**(하위 메뉴, `aria-haspopup`, → 로 열고 ← · Esc로 닫고 포커스는 그 항목으로): 색 — 채움 · 선 색 · 글자 색 · 그림자 색 / 간격 — 간격 · 안쪽 여백(4방향) · 위 · 아래 · 왼쪽 · 오른쪽 / 반경 — 모서리 4곳 · 왼쪽 위 · 오른쪽 위 · 왼쪽 아래 · 오른쪽 아래. 그 밖의 종류는 항목을 보이지 않는다. 선택이 없으면 `aria-disabled`.
- 메시지: `APPLY_VARIABLE{reqId, id, target?}` → `VARIABLE_APPLIED{reqId, applied, skipped, name}` / `ERROR{op:'APPLY_VARIABLE'}`. target 값: `fill · stroke · text · shadow · gap · padding · padding-top · padding-right · padding-bottom · padding-left · radius · radius-tl · radius-tr · radius-bl · radius-br`(없으면 기본 속성).

### 4.8 상세 팝업 (합침)

- "상세"와 "고치기…"를 하나로. 열자마자 고칠 수 있다(v3 고치기 그대로). 처음 포커스 [닫기](복제 직후에만 이름 칸).
- 더하는 것:
  - 제목 줄 오른쪽 [⧉ 이름 복사]. CSS 줄 `--{css 이름}` + [⧉]. 누르면 단추 글자가 1.5초 "복사됨"으로 바뀌고 포커스는 그 단추에 남는다(상태 줄은 팝업 뒤라 쓰지 않음).
  - 모드 값이 별칭이면 값 칸 오른쪽 [→](툴팁 "가리키는 변수로"). 대상이 삭제된 별칭이면 숨긴다. 고친 내용이 있으면 v3 "닫기 전 확인"을 거친 뒤 이동: 팝업을 닫고 변수 탭으로 바꾸고, 대상의 컬렉션을 고르고(검색은 지움), 그 그룹을 펼쳐 그 알약 · 줄로 포커스. 상태 줄 "{이름}(으)로 옮겼어요 · [← 되돌리기]"(고른 컬렉션 · 접힘 · 검색 · 스크롤 복원). 라이브러리 대상이면 이동하지 않고 "라이브러리 변수예요 · 원본 파일에서 관리해요".
  - 쓰인 곳 머리 "{n}곳 · [모두 선택]"(최대 200 — v3 그대로, 목록 기준 안에서). "{n}곳"의 툴팁 "인스턴스 안쪽 포함". 목록 기준이 없으면 "레이어를 선택하면 그 안에서 찾아요"(버튼 없음). 간접만 쓰이면 "—"(간접 줄을 두지 않는다).
- 값 복사 단추는 두지 않는다(값 칸을 골라 ⌘C).
- 포커스 순서: [⧉ 이름 복사] → 이름 칸 → 모드마다 값 칸 · [▾] · [→] → CSS [⧉] → 쓰인 곳([찾기] · [모두 선택] · 레이어 단추들) → (확인 줄) → [닫기]/[취소] → [저장]. 라이브러리 상세: [⧉ 이름 복사] → CSS [⧉] → 쓰인 곳 → [닫기].

### 4.9 새 변수 · 복제 · 삭제

**새 변수** (변수 탭 ＋ › 새 변수)
- 팝업(상세와 같은 틀): 컬렉션(읽기, 지금 고른 컬렉션) · 이름 · 종류(색 · 숫자 · 글자 · 참거짓, 기본은 지금 보이는 첫 그룹의 종류) · 모드별 값(값 ↔ 별칭, 고치기의 칸 · [▾] 그대로) · [취소] [만들기].
- 이름은 비워 둔다. 이름 검사 · 값 검사는 고치기와 같다(새 변수용 가상 self로 `nameError` · `aliasCandidates`를 부른다). 기본 모드 값은 필수, 다른 모드는 비우면 기본 모드 값.
- 용도(scopes)는 **최종 이름**의 종류로: 간격 GAP, 반경 CORNER_RADIUS, 크기 WIDTH_HEIGHT, 선 두께 STROKE_FLOAT, 투명도 OPACITY, 색 ALL_FILLS · STROKE_COLOR · EFFECT_COLOR, 글자는 그 속성(FONT_SIZE · LINE_HEIGHT · LETTER_SPACING · FONT_FAMILY), 기타는 ALL_SCOPES.
- 만든 뒤 팝업을 닫고 변수 표를 다시 읽어, 그 그룹을 펼치고 새 변수로 포커스 · 스크롤. ⌘Z 한 번. 사용자 컬렉션에도 된다(v3 §2.13 13.1 — 사용자가 직접 하는 일).
- 메시지 `CREATE_VARIABLE{reqId, collectionId, name, type, values, scopes}` → `VARIABLE_CREATED{reqId, id}` / `ERROR{op}`(이름 거절은 팝업 오류 줄).

**복제** (우클릭 › 복제)
- 같은 컬렉션에: 모든 모드 값(별칭 포함) · 용도 · 설명 · 게시 숨김 · 코드 문법(codeSyntax)을 복사. 플러그인 표시(`dsl.autoRole`)는 복사하지 않는다.
- 이름 `{이름}-copy`, 있으면 `-copy-2` · `-copy-3`(겹침 판단은 `nameError`와 같게 대소문자까지 같을 때).
- 새 변수는 피그마가 컬렉션 끝에 만든다 — 목록은 피그마 순서라 그룹 끝에 보인다(받아들임). 만든 뒤 상세를 열고 이름 칸에 포커스.
- 메시지 `DUPLICATE_VARIABLE{reqId, id}` → `VARIABLE_DUPLICATED{reqId, newId}`.

**새 변수 · 복제의 무료 개수 제한** — 무료는 개수를 제한한다(§9에서 숫자 · 기준 결정). 한도에 닿으면 ＋ › 새 변수 · 복제가 잠금(사유 "무료로는 {n}개까지 만들 수 있어요 · [라이선스 →]").

**삭제** (우클릭 › 삭제, 무료)
- 확인 팝업(늘): 제목 "{이름} 변수를 지울까요?". 이 변수를 가리키는 로컬 변수가 있으면 "이 변수를 가리키는 변수 {m}개는 '삭제된 변수'를 가리키게 돼요". 늘 "연결된 레이어 · 스타일은 '삭제된 변수'가 돼요". [취소] [삭제](`--danger`). 처음 포커스 [취소], Esc = 취소. 라이브러리 게시 경고는 넣지 않는다(사용자 결정).
- 지운 뒤 다시 읽고, 포커스는 같은 그룹의 다음 항목(알약 · 동그라미 · 줄), 없으면 이전, 그것도 없으면 그룹 머리.
- ⌘Z로 되돌린다. 사용자 컬렉션도 지울 수 있다.
- 메시지 `DELETE_VARIABLE{reqId, id}` → `VARIABLE_DELETED{reqId, id}`. {m}은 UI가 변수 표에서 센다(모든 모드의 별칭 대상).

### 4.10 ⚙ 설정

- 머리: "← 설정". 내용은 v3 설정 탭 그대로(기본값 · 라이선스).
- ⚙는 어느 탭에서든 열리고, ←로 그 탭의 원래 화면으로 돌아온다.
