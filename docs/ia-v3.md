## 1. 왜 바꾸나 (문제)

1. **나누는 기준이 섞여 있었다.** 시작은 "처음 쓰는 사람", 만들기·적용은 "작업 순서", [변수]는 "대상", 설정은 "기타"를 기준으로 했다. 그래서 "변수를 보고 싶다"는 목적 하나에 갈 곳이 3곳이었다.
   - 피드백 1: "이미 변수가 있는데 '만들기'에 들어가 없다는 걸 확인한 뒤 '적용'으로 이동했다."
   - 피드백 2: "무엇이 어디에 연결됐는지 알 수 없다."
   - 피드백 3: "[변수]가 적용 탭 안에서 열리는 건가?"
2. **우회로가 계속 늘었다.** 기존 변수 배너 2개, 연결 카드에서 변수 관리로 가는 링크가 그 예다.
3. **같은 데이터를 두 번 그렸다.** 연결 현황과 변수 관리 사용처는 같은 함수(`scanBindings`)를 쓴다.
4. **노트북 화면을 너무 가렸다.** 13인치(1470×956 가정)에서 400×660 창은 높이의 약 75%를 가린다. 510이면 약 58%, 최소화하면 약 5%다(추정).
5. **역할이 사용자 의도와 반대였다.** 사용자 원칙은 "플러그인은 쓰인 변수를 보고 변수를 고치는 도구, 레이어에 붙은 변수를 바꾸는 일은 피그마"다. 그런데 지금 플러그인에는 레이어 연결을 바꾸는 기능만 있고, 변수를 고치는 기능은 없다.

## 2. 원칙

1. **탭 = 다루는 대상.**
   - **변수 탭:** 파일의 변수를 보고 만든다. 고치기는 다음 PR이다. 만드는 일(시작 화면, 만들기)은 선택한 레이어를 읽는다.
   - **레이어 탭:** 선택한 레이어에 변수를 붙이고, 이름을 정리하고, 컴포넌트로 만든다.
   - **설정 탭:** 자주 안 바꾸는 값과 라이선스.
2. **보기는 변수 탭, 붙이는 작업은 레이어 탭.**
3. **유료/무료는 탭이 아니라 버튼에서 표시한다.**
   - 기준: 있는 자산을 쓰는 일은 무료, 새로 만드는 일은 유료.
   - 잠긴 컨트롤은 `disabled` 대신 `aria-disabled="true"`로 둔다. 그래야 키보드로 포커스할 수 있다.
   - 누르면 동작하지 않고 상태 줄에 "유료 기능이에요 · 설정 › 라이선스에서 풀 수 있어요"를 띄운다.
   - 툴팁은 기존 설명 뒤에 " · 유료 기능 · 설정 › 라이선스"를 붙인다(`setLockTitle` 수정).
4. **변수 관리 범위.**
   - v3에서 하는 것: 보기 · 복사 · 사용 레이어 선택 · 상세(읽기)
   - 다음 PR: 별칭 대상 · 이름 · 값 고치기
   - 하지 않는 것: 변수 삭제, 레이어 연결 일괄 교체
   - 변수 삭제를 하지 않는 이유: 이 파일을 라이브러리로 쓰는 다른 파일의 연결이 끊긴다. 파일 안에서는 ⌘Z로 되돌릴 수 있어도, 다른 파일에서 끊긴 연결은 되돌아오지 않는다.
5. **400×510 화면 규칙.**
   - 버튼은 카드 제목 줄에 둔다. 목록보다 위다(지금 구조).
   - **sticky(스크롤해도 고정):**
     - 지금처럼 유지: 탭 바, 선택 표시줄, 카드 머리(`.step-head`, 버튼 줄)
     - 새로 추가: 변수 목록 영역 **안**의 열 머리, 컬렉션 구역 머리, 그룹 머리
   - 각 화면 **첫 카드**의 주 버튼은 스크롤 없이 보인다.
   - 긴 목록(변수 목록, 연결·이름 미리보기 트리)은 목록 영역 안에서만 스크롤한다. 페이지 가로 스크롤은 0이다.
   - 변수 목록 영역은 약 11줄이다(줄 높이 28px, 시안 측정). 열 머리가 없으면 약 12줄이다.
6. **상태 기억.**
   - 플러그인이 열려 있는 동안 기억하는 것: 탭별 하위 화면, 단계, 스크롤, 계층 칩, 직접 펼치거나 접은 그룹, 고른 모드, 검색어.
   - 다시 열면 모두 처음 상태로 돌아간다.
7. **피그마 기능에 대한 가정은 검증된 것만 쓴다.**
   - 레이어 변경 감지(`page.on('nodechange')`)는 검증하지 못했다(§12.2). 그래서 쓰지 않는다.
8. **테마.** 플러그인은 라이트 고정이다(`color-scheme: light`, 지금과 같음). 다크 테마는 v3 범위 밖이다.
9. **용어.**
   - 사용자에게 보이는 말은 **연결**(바인딩 아님), **건너뜀**(스킵 아님)으로 쓴다.
   - 컬렉션의 G/S/C는 **계층**이라고 부른다. **역할**은 색 역할(면·글자 등)에만 쓴다.
   - 플러그인 안 화면 이동은 "→"로 표시한다. "↗"는 외부 링크(결제 페이지)에만 쓴다.

```
│   │    ├─ 머리줄: [준비 현황 n/7 ▾] [변수 없는 값 찾기 →]  [+] [⋯] [↻]
│   │    ├─ 계층 칩: (모두 17/115) (Semantic S 7/25) (Global G 10/90) …   [🔍]
│   │    ├─ 목록: 컬렉션 구역 머리 → 그룹 머리 → 쓰는 변수 행
│   │    │        구역 끝: 안 쓰는 그룹 n개 ▸
│   │    ├─ LIB · 선택에서 쓰는 것 (있을 때)
│   │    ├─ 삭제된 변수에 연결된 곳 n개 (있을 때)
│   │    ├─ 행 메뉴: 이름 복사 · 값 복사 · CSS 변수명 복사 · 사용 레이어 선택 · 가리키는 변수로 이동 · 상세
│   │    └─ [⋯] 메뉴: 컬렉션 계층 지정… · 코드로 내보내기…
│   └─ 만들기 (하위 화면, "← 돌아가기")
│        ├─ 맨 위: 한 번에 정리 (마법사, 접힘)
│        └─ 4단계: 색 → 토큰 → 테마(다크) → 타이포
│
├─ 레이어
│   ├─ 하위 탭(밑줄 모양): 연결 · 이름 · 컴포넌트
│   ├─ 연결: [미리보기] [선택한 항목에 연결] · 텍스트 스타일 [기존 스타일 연결]
│   │        → 변수 이름 필터 · 후보 트리 → 결과 요약 + 건너뜀 사유 칩 + "변수 탭에서 보기 →"
│   ├─ 이름: 미리보기 → 이름 적용 · 잠금 제외
│   └─ 컴포넌트: 후보 스캔 · 닮은 스캔 · 등록 · 묶기 · 베리언트 분류 · 누락 조합 생성
```

### 3.1 화면 사이 이동 (전부)

| 변수 › 목록 "변수 없는 값 찾기 →" | 레이어 › 연결 (미리보기 자동 실행, 예외 §4.5) | 선택한 레이어에서 변수가 없는 값을 찾을 때. 선택이 없으면 `aria-disabled` |

## 4. 화면별 상세

글자 와이어프레임은 폭 400, 높이 510 기준이다. 픽셀까지 맞추는 것이 목표가 아니라 배치와 우선순위를 정하는 용도다. 와이어 안의 숫자와 사유 칩은 **예시**다. 실제 문구는 i18n 키를 따른다.

### 4.1 공통 셸

```
┌────────────────────────────────────────┐
│ [ 변수 ]  레이어   설정              —  │  ← 탭 바 (지금 .tabs 모양, sticky)
├────────────────────────────────────────┤
│ ● Card · 하위 42                         │  ← 선택 표시줄 (설정만 숨김, sticky)
├────────────────────────────────────────┤
│                탭 내용                  │
└────────────────────────────────────────┘
```

**탭 모양 3단계 (서로 구분되게)**

| 단계 | 모양 |
|---|---|
| 상단 탭 | 지금 `.tabs` (회색 바탕 + 흰 알약) |
| 레이어 하위 탭 | 밑줄 글자 탭. 11px/600, 활성은 2px `--accent` 밑줄, 바탕 없음 |
| 계층 칩 | 작은 칩. 10.5px, 높이 24px, `--r-sm` 테두리. 활성은 `--accent-subtle` 바탕 + `--accent-strong` 글자 |

**선택 표시줄 문구** (`role="status"`, 포커스 받지 않음)

| 상황 | 문구 |
|---|---|
| 1개 선택 | `● {레이어 이름} · 하위 {n}` (이름은 말줄임) |
| 여러 개 선택 | `● 레이어 {k}개 · 하위 {n}` |
| 선택 없음 | `● 선택 없음 — 캔버스에서 레이어를 선택하세요` |
| 목록 기준과 다를 때 (③) | `● 레이어 3개 선택 · 목록 기준: Card` + `[기준 바꾸기]` |

- 지금 문구의 "바인딩 후보 n개"는 뺀다. 다른 화면의 선택 안내도 "레이어를 선택하세요"로 통일한다.

**포커스 순서**
1. 상단 탭(정지점 1개, ←→)
2. [—]
3. 화면의 컨트롤
4. 목록(정지점 1개)

- 변수 목록의 컨트롤 순서: [준비 현황] → [변수 없는 값 찾기] → [+] → [⋯] → [↻] → 계층 칩(정지점 1개, ←→) → [🔍] → 모드 ▾(있을 때) → 목록
- 최소화했다가 펼친 뒤에는 포커스를 [—]로 돌려놓는다.

**접근성 이름**

| 컨트롤 | 이름 |
|---|---|
| [—] | 최소화 |
| [+] | 선택에서 변수 만들기 |
| [⋯] (머리줄) | 목록 메뉴 |
| 행 ⋯ | 변수 메뉴 |
| [↻] | 다시 읽기 |
| 🔍 | 변수 검색 |

- 상태 줄은 `aria-live="polite"`로 둔다.

**다시 읽기 (④)**

- **언제:**
  - 포인터가 창 밖으로 나갔다가 다시 들어올 때(`pointerleave` → `pointerenter`)
  - 창이 포커스를 다시 얻을 때(`window` `focus`)
  - 둘 다 400ms 뒤에 한 번 실행한다. 창 안에서 움직일 때는 실행하지 않는다.
- **최소화 상태에서는 하지 않는다.** 펼칠 때 한 번 한다.
- **화면별로 읽는 것**

| 화면 | 다시 읽는 것 |
|---|---|
| 변수 › 시작 화면·목록 | `GET_PREREQ`(시작/목록 판정, 준비 현황) + `GET_VAR_TABLE` + 사용 수(⑤ 300개 규칙 적용) |
| 변수 › 만들기 | `GET_PREREQ`만. 카드 미리보기는 다시 실행하지 않는다 |
| 레이어 › 연결 | `GET_PREREQ`. 미리보기 결과가 있으면 그 위에 "피그마에서 바뀌었을 수 있어요 · [미리보기 다시]" 한 줄 |
| 레이어 › 이름·컴포넌트 | 읽지 않음. 미리보기·스캔 결과가 있으면 같은 한 줄 안내 |
| 설정 | 읽지 않음 |

- **반영 방식**
  - 응답이 이전과 같으면 다시 그리지 않는다.
  - 다르면 스크롤과 포커스 행을 지키며 바뀐 부분만 반영한다.
  - 메뉴·팝업·팝오버가 열려 있거나 포인터가 눌린 동안에는 닫히거나 떼어질 때까지 반영을 미룬다.

### 4.2 변수 탭 — 불러오는 중

- 첫 `PREREQ_STATE`가 오기 전에는 시작 화면도 목록도 그리지 않는다. 대신 "변수 정보를 불러오는 중…" 한 줄만 보인다.
- 지금처럼 시작 직후 `GET_PREREQ`를 1번 보낸다.

### 4.3 변수 탭 — 시작 화면 (로컬 변수 0개)

```
┌────────────────────────────────────────┐
│ ● 선택 없음 — 캔버스에서 레이어를 선택하세요 │
│ 아직 로컬 변수가 없어요                   │
│ 선택한 화면에서 만들어 보세요              │
│ ⓘ 무료 버전은 변수를 새로 만들지 않아요 ·   │  ← 무료일 때만
│   추출·연결·이름 정리는 무료 · 라이선스 →   │
│ ┌ 한 번에 정리 ───────────────────────┐ │
│ │ 선택한 화면의 색·간격을 변수로 만들고  │ │
│ │ 붙입니다                            │ │
│ │ ☐ 역할 매핑🔒 ☐ 다크🔒 ☐ 텍스트 스타일🔒│ │  ← 무료: 해제 + aria-disabled
│ │                        [전체 실행]  │ │  ← 선택 없으면 aria-disabled
│ └─────────────────────────────────────┘ │
│ ── LIB · 선택에서 쓰는 것 ──              │  ← 선택에 라이브러리 연결이 있을 때
│    ■ Background/Danger/Default  LIB 1곳 │
│ ⓘ 라이브러리 변수는 원본 파일에서 관리해요. │
│   같은 변수를 여기서 또 만들 필요는 없어요.  │
│ [색부터 하나씩 만들기 →]   준비 현황 n/7 ▾ │
└────────────────────────────────────────┘
```

- **보이는 조건:** 로컬 변수 0개(`PREREQ_STATE`의 `tierVars + otherVars === 0`).
- **무료 안내(①):**
  - 무료 티어일 때만 마법사 카드 위에 보인다. "라이선스 →"를 누르면 설정 탭으로 간다.
  - 잠긴 옵션(역할 매핑, 다크, 텍스트 스타일)은 체크를 해제하고 `aria-disabled`로 둔다.
  - 무료일 때 마법사 카드 설명은 "선택한 화면에서 값을 뽑고 이름을 정리합니다"로 바꾼다. 무료에서 마법사가 실제로 하는 일은 추출 · 연결 · 이름 정리다(`wizard.ts` 유료 단계 건너뜀).
  - "색부터 하나씩 만들기 →"는 무료여도 보인다. 색 추출은 무료이고, 그다음 "색 변수 만들기"에서 잠금 사유를 보여 준다.
- **전체 실행:** 선택이 없으면 `aria-disabled`이고, 누르면 상태 줄에 "선택이 없어요 — 캔버스에서 레이어를 선택하세요"를 띄운다.
- **LIB 구역(②):** 목록의 LIB 구역(§4.4)과 같은 규칙이다. 시작 화면에서는 사용 수 조회를 이 구역을 위해서만 보낸다.
- **준비 현황:** 맨 아래 링크로 둔다. `n`은 `pipeline.ts`의 완료 수다. 로컬 텍스트 스타일만 있어도 1 이상일 수 있다.
- **마법사 완료**
  - 만든 변수가 1개 이상이면: 머리를 "변수 {n}개를 만들었어요"로 바꾸고 [변수 목록 보기]를 보여 준다. 준비 현황도 다시 계산한다.
  - 0개면(무료, 취소, 실패): 머리는 그대로 두고 마법사 요약만 보여 준다. [변수 목록 보기]는 없다.
- **마법사 화면 요소는 1개다.** 시작 화면과 만들기 맨 위 중 보이는 곳으로 옮겨 붙인다. 실행 중에는 진행과 요약이 그 카드에 남고, 탭을 바꿔도 실행은 계속된다.
- "다시 보지 않기" 배너(`#onboardBanner`)와 설정값 `hideOnboard`는 없앤다. 시작 화면은 로컬 변수 0개일 때만 나오므로 배너가 필요 없다.

### 4.4 변수 탭 — 변수 목록

```
┌────────────────────────────────────────┐
│ ● Card · 하위 3                          │
│ 준비 현황 5/7 ▾   변수 없는 값 찾기 → [+][⋯][↻] │
│ (모두 17/115)(Semantic S 7/25)(Global G 10/90)›[🔍] │
│ 이름                값 Light ▾    사용   │  ← 보이는 모드가 2개 이상일 때만 이 줄
```

#### 머리줄

| 요소 | 동작 |
|---|---|
| `준비 현황 n/7 ▾` | 바로 아래에 **팝오버**(`.ctx-menu`와 같은 모양, 폭 240px)로 7단계를 연다. 목록 높이는 바뀌지 않는다. `aria-expanded`. Esc나 바깥 클릭으로 닫힌다. 줄을 누르면 닫히고 §3.1 표대로 이동한다 |
| `변수 없는 값 찾기 →` | `button.link`(테두리 없음). 선택이 없으면 `aria-disabled`. 툴팁 "선택에서 변수로 바꿀 수 있는 색·간격을 찾아 연결 미리보기를 엽니다" |
| [+] | 아이콘만. 만들기 › 색으로 간다. 툴팁 "선택한 화면에서 변수 만들기(색·토큰·테마·타이포)" |
| [⋯] | 컬렉션 계층 지정… · 코드로 내보내기… |
| [↻] | 지금 화면의 다시 읽기(§4.1 표)를 바로 실행한다. ⑤의 300개 제한을 무시한다. 실행 중에는 아이콘이 돈다. 끝나면 상태 줄에 2초간 "다시 읽음 · 변경 없음" 또는 "다시 읽음 · 사용 수가 바뀐 변수 n개" |

#### 계층 칩

- **순서:** [모두] → 로컬 컬렉션을 계층 순서로(Component → Semantic → Global → 계층 없음). 같은 계층 안에서는 피그마 순서를 따른다.
- **처음:** [모두]. 사용자가 고르면 세션 동안 기억한다.
- **표기:** `컬렉션 이름` + 계층 배지(G/S/C, 지정 없으면 "?") + 숫자.
  - 배지는 누를 수 없는 표시다(`aria-hidden`).
  - 계층 지정은 [⋯] › "컬렉션 계층 지정…"으로만 연다. 칩 안에 누를 수 있는 요소를 넣지 않는다.
- **숫자(⑦)**
  - 선택이 있으면 `사용/전체`(예: `10/90`). 툴팁 "선택에서 쓰는 변수 10개(직접 4 · 간접 6) / 전체 90개".
  - 선택이 없으면 `전체`(예: `90`).
  - 사용 수를 기다리는 동안에는 "…"를 보인다.
- **넘칠 때:** 칩 줄 안에서만 가로로 밀린다. 오른쪽 끝에 16px 페이드를 넣는다.
- **라이브러리 컬렉션은 칩에 넣지 않는다.** LIB 구역에서 보여 준다.
- **접근성 이름 예:** "Global, Global 계층, 선택에서 10개 사용, 전체 90개"

#### 검색

- [🔍]를 누르면 칩 줄 오른쪽에 입력칸이 열린다(최소 160px, ✕, Esc로 닫힘). 칩 줄은 왼쪽으로 줄어든다.
- 범위는 지금 고른 칩이다. [모두]일 때는 LIB 구역도 포함한다.
- **검색어가 있으면 접힘과 "쓰는 것만" 규칙을 무시하고 맞는 행을 모두 보여 준다.** 안 쓰는 행은 "안 쓰는 행" 모양으로 보인다.
- 결과가 없으면: "'{검색어}'와 맞는 변수가 없어요 · [모두에서 찾기] [검색 지우기]"

#### 쓰는 변수 판정과 사용 수

- **직접 사용:** 목록 기준(③) 레이어 안에 그 변수가 연결돼 있다.
- **간접 사용:**
  - 직접 사용 변수가 별칭으로 가리키는 변수다. 모든 모드를 보고, 최대 5단계까지 따라간다.
  - 직접과 간접이 겹치면 직접으로 센다.
  - 라이브러리 변수를 가리키는 별칭도 따라간다(LIB 구역의 "↳ 간접").
- **사용 수의 단위는 "곳"이다.** 연결된 속성 자리 수다(지금 `vm.uses` "{n}곳"과 같음). 툴팁은 "레이어 {k}개 · {n}곳".
  - 그래서 사용 수 조회 응답은 변수마다 `{ places, layers }`를 **상한 없이** 담는다(§6).

#### 목록 구조 (⑥)

- 맨 위에 **열 머리**(이름 · 값 ▾ · 사용)를 둔다. 보이는 모드가 2개 이상일 때만 둔다.
- **컬렉션 구역 머리:** 컬렉션마다 한 번. 이름 + 계층 배지 + 칩과 같은 숫자.
  - 칩 하나만 고른 상태에서는 구역 머리가 1개다.
- **그룹 머리:** 그룹 키는 **컬렉션 + 경로**다. `groupRows`는 키에 컬렉션을 넣도록 고친다.
  - 이름에 "/"가 없는 변수는 그 컬렉션의 "(그룹 없음)" 그룹에 넣는다.
- **그룹 머리 구성** (11px/600, `--text-2`, 높이 28px, 바탕 `--surface-2`, sticky)
  - 왼쪽: 접기 버튼 ▾/▸ (`aria-expanded`)
  - 가운데: 경로
  - 오른쪽 숫자
    - 선택이 있으면 `사용/전체`
    - 선택이 없으면 `전체`
  - 오른쪽 끝: 별도 글자 버튼 **"+{m} 안 씀"**(펼친 뒤에는 "숨기기"). 높이 24px. 이름은 "안 쓰는 변수 {m}개 보기". 안 쓰는 변수가 있을 때만 보인다.

#### 펼침 규칙

**선택이 있을 때**
- 쓰는 변수가 있는 그룹은 펼친다. **쓰는 행만** 보인다.
- 하나도 안 쓰는 그룹은 **각 컬렉션 구역 끝**에 "▸ 안 쓰는 그룹 n개" 한 줄로 모은다. 누르면 그 그룹 머리들이 접힌 채로 나온다.
- 선택이 로컬 변수를 하나도 안 쓰면, 목록 위에 "이 선택은 로컬 변수를 쓰지 않아요 · [변수 없는 값 찾기 →]"를 둔다.

**선택이 없을 때**
- 지금 칩에 보이는 그룹 수를 센다([모두]이면 전체 합계).
  - 10개 이하면 모두 펼친다(모든 행).
  - 넘으면 모두 접고, 목록 위에 "프레임을 선택하면 쓰는 변수만 펼쳐져요"를 둔다.

**사용자가 직접 펼치거나 접은 그룹**
- 세션 동안 그 상태를 기억한다.
- 선택이 있을 때는 그 그룹을 쓸 때만 적용한다. 안 쓰는 그룹이 되면 "안 쓰는 그룹" 줄로 간다.

**포커스 행이 숨겨질 때**
- 포커스를 그 그룹 머리로 옮긴다.
- 상태 줄에 "선택에서 안 쓰여 숨겼어요"를 띄운다.

**성능**
- 접힌 그룹의 행은 그리지 않는다.

#### 행

| 열 | 내용 |
|---|---|
| 이름 | 마지막 토막. 툴팁은 전체 경로. 아이콘(색 견본 / # / T / ◐) |
| 값 | 고른 모드의 값. 별칭은 알약(`→ gray/50`, `tabindex=-1`). 색 견본은 별칭을 따라가 실제 색 |
| 사용 | `12곳` / `↳ 간접` / `안 씀` / `—`(선택 없음) |

**행 상태별 모양** (흐림에 opacity를 쓰지 않음, 색만으로 구분하지 않음)

| 상태 | 모양 |
|---|---|
| 직접 사용 | 이름 `--text` 600, "12곳" |
| 간접 사용 | 이름 `--text` 400. "↳ 간접" 툴팁: "직접 붙어 있진 않고, {첫 별칭 이름} 같은 별칭을 통해 쓰여요" |
| 안 씀 (펼친 경우) | 이름 `--text-2`(대비 6.05:1), 글자 "안 씀" |
| 선택 없음 | 이름 `--text` 400, "—" |

**값 열과 모드**
- 값 열 머리 ▾에는 보이는 컬렉션들의 모드 이름을 모은다. 고른 모드는 세션 동안 기억한다.
- 고른 모드가 없는 컬렉션은 기본(첫) 모드 값을 보여 준다.
- **"값 복사"와 색 견본도 고른 모드를 따른다**(지금 `currentModeCell`/`resolveColor`의 첫 모드 고정을 바꿈).

**별칭 이동** (알약 또는 메뉴 "가리키는 변수로 이동")
1. 칩을 [모두]로 바꾸고, 검색어를 지우고, 그룹을 펼친 뒤, 그 행에 포커스한다.
2. 상태 줄에 "{이름}로 이동 · [← 되돌리기]"를 띄운다. 되돌리기는 이전 칩, 검색어, 스크롤을 복원한다.
3. 대상이 라이브러리 변수이면 LIB 구역의 행으로 간다. 그 행이 없으면 "라이브러리 변수예요 · 원본 파일에서 관리해요"를 띄운다.

#### LIB 구역 (② 시작 화면과 같음)

- 목록 기준 레이어가 라이브러리 변수를 쓸 때만, 로컬 구역들 **뒤**에 나온다. 제목은 "LIB · 선택에서 쓰는 것".
  - [모두]일 때만 보이고, 컬렉션 칩 하나를 고르면 숨는다.
- **행:** 실제 이름 + `LIB` + 사용 수(직접 "n곳" / "↳ 간접").
  - 이름·컬렉션·값은 `getVariableByIdAsync`로 찾는다(§12.1 검증).
- **메뉴:** 이름 복사 · 값 복사 · CSS 변수명 복사 · 사용 레이어 선택 · 상세. 수정 메뉴는 이후에도 없다.
- 별칭 알약이 라이브러리 변수를 가리키면 "(다른 파일 변수)" 대신 실제 이름 + `LIB`로 표시한다.

#### 삭제된 변수에 연결된 곳

- 연결 ID를 `getVariableByIdAsync`로 찾았는데 `null`이면, 목록 맨 끝에 "삭제된 변수에 연결된 곳 {n}개 [선택]" 한 줄을 둔다.
- [선택]을 누르면 그 레이어들을 캔버스에서 선택한다.
- 지금 "(삭제된 변수)" 이름으로 섞여 보이던 것을 대신한다.

#### 선택이 바뀔 때

- 선택 표시줄은 바로 바뀐다.
- **400ms 기다린 뒤 사용 수를 요청한다.**
  - 요청하는 동안 칩 숫자는 "…"로 바뀌고, 상태 줄에 "선택에서 쓰는 변수 읽는 중…"이 뜬다.
  - 목록은 비우지 않는다. 응답이 오면 한 번에 바꾼다.
- **바뀌는 것:** 펼침, 강조, 칩·구역·그룹 숫자, LIB 구역, 삭제된 변수 줄.
- **바뀌지 않는 것:** 로컬 변수 목록 자체.
- 열린 상세 팝업은 닫지 않는다.

#### 큰 선택 (⑤)

- 선택 노드 수(`SELECTION_STATE.scanned`)가 300을 넘으면 사용 수를 자동으로 요청하지 않는다. 지금 `AUTO_SCAN_MAX`와 같은 기준이다.
- 이때 칩 숫자는 "?"로 보이고, 목록 위에 "선택이 커서 자동으로 읽지 않아요 · [읽기]"가 나온다. [읽기]나 [↻]를 누르면 읽는다.
- 마법사가 실행 중이면 자동 요청하지 않는다(지금과 같음).

#### 목록 기준 (③)

- 기본적으로 목록 기준은 "지금 선택"이다.
- **플러그인이 만든 선택은 목록 기준을 바꾸지 않는다.** "사용 레이어 선택", 건너뜀 사유 칩, 삭제된 변수 [선택]이 여기에 해당한다(`SELECTION_STATE.selfSelect`, 지금 있는 표시).
  - 이때 선택 표시줄은 "● 레이어 3개 선택 · 목록 기준: Card [기준 바꾸기]"다.
  - 사용 수 조회는 기준 레이어 ID를 담아 보낸다(§6).
- **기준이 바뀌는 때**
  - [기준 바꾸기]나 [↻]를 누를 때
  - 사용자가 캔버스에서 직접 선택을 바꿀 때(`selfSelect`가 아닌 변경)

#### 행 메뉴 (우클릭 / 행 ⋯ / Shift+F10)

| 항목 | 조건 |
|---|---|
| 이름 복사 · 값 복사 · CSS 변수명 복사 | 항상 |
| 사용 레이어 선택 | 직접 사용이 있을 때. 간접만 있으면 `aria-disabled` + 보조 문구 "별칭을 통해서만 쓰여요 — {첫 별칭 이름}에서 선택하세요". 선택이 없으면 보조 문구 "레이어를 선택하면 그 안에서 찾아요" |
| 가리키는 변수로 이동 | 값이 별칭일 때만(`vm.jumpAlias` 키 사용) |
| 상세 | 항상 |

- **"사용 레이어 선택"** 은 그 변수를 쓰는 레이어를 code 쪽에서 **새로 찾아** 선택한다(상한 없음, §6 `SELECT_VAR_USERS`). 그래서 600개 상한에 걸려 선택이 비는 일이 없다.
- 교체, 이름 변경, 삭제는 없다.

#### 상세 팝업

- **공통:** 컬렉션 · 계층, 모드별 값, 용도(scopes), 설명, 쓰인 곳
- **간접 사용 행:** 쓰인 곳 칸에 "별칭을 통해 쓰임: {별칭 이름들} ({합계}곳)"을 보여 준다. "선택 안에서는 쓰이지 않아요"를 보이지 않는다.
- **LIB 행:** 컬렉션 칸에 "라이브러리 · {컬렉션 이름}", 맨 아래 "원본 파일에서 관리해요"
- **"상세"로 문구를 통일한다**(`vm.detail` "상세 보기…" → "상세").

#### 키보드 (목록은 정지점 1개, `role="treegrid"`)

| 키 | 동작 |
|---|---|
| ↑ ↓ | 구역 머리, 그룹 머리, 행을 모두 지나간다 |
| → / ← | 그룹 펼치기 / 접기 (행에서 ←는 그룹 머리로) |
| Enter | 행이면 상세, 머리면 펼침 전환 |
| Shift+F10 / 컨텍스트 메뉴 키 | 행 메뉴 |
| Esc | 메뉴·팝업·팝오버 닫기 |

- `aria-level`: 구역 1, 그룹 2, 행 3.
- 행 안의 알약과 ⋯는 `tabindex=-1`이다. 키보드로는 메뉴를 쓴다.
- 행 ⋯의 누를 수 있는 영역은 24×24 이상이다.

#### 계층 지정 후

- `SET_COLLECTION_ROLE` 응답 뒤에 `GET_VAR_TABLE`을 다시 요청해 칩 배지와 구역 순서를 갱신한다.

### 4.5 변수 탭 — 만들기 (하위 화면)

```
┌────────────────────────────────────────┐
│ ● Card · 하위 42                         │
│ ← 돌아가기                               │
│ ▸ 한 번에 정리 (마법사)                   │  ← 접힘. 펼치면 4.3과 같은 카드
│ (색)─(토큰)─(테마)─(타이포)               │  ← 지금 단계 레일 그대로
├────────────────────────────────────────┤
│ 카드 제목            [미리보기][적용][다음→]│  ← 카드 머리 (지금처럼 sticky)
│ (지금 만들기 탭의 각 단계 카드 그대로)      │
└────────────────────────────────────────┘
```

- 지금 만들기 탭의 4단계를 그대로 옮긴다(카드, 미리보기, 잠금, "다음 →").
- **토큰 단계에 보이는 카드는 1개(간격·크기)다.**
  - 시맨틱 매핑 카드는 지금처럼 늘 숨김이다(`data-always-hidden`).
  - 역할 매핑은 토큰을 적용할 때 자동으로 만들어진다.
- 타이포 단계의 "기존만 연결"은 레이어 › 연결로 옮긴다. 이 카드 안내(`textStyle.hint`)는 "화면에 붙이기는 레이어 › 연결"로 바꾼다.
- 마지막 단계(타이포)의 출구: "변수 탭으로", "레이어에 붙이기 →".
- "← 돌아가기"는 변수 탭 첫 화면으로 가고, `GET_PREREQ`와 `GET_VAR_TABLE`을 다시 요청한다.
- 무료일 때 잠긴 버튼은 §2.3 규칙을 따른다.

### 4.6 레이어 탭 — 연결

```
┌────────────────────────────────────────┐
│ ● Card · 하위 3                          │
│  연결   이름   컴포넌트                   │  ← 밑줄 하위 탭
│  ‾‾‾‾                                   │
├────────────────────────────────────────┤
│ 변수 연결    [미리보기][선택한 항목에 연결] │  ← 카드 머리
│ 텍스트 스타일          [기존 스타일 연결]  │  ← 한 줄
│ 후보 18 · 건너뜀 4  [매칭 없음 3][숨김 1]  │  ← 사유 칩 (예시)
│ [변수 이름 필터        ]                  │  ← 미리보기가 있을 때
│ ┌ 후보 트리 (영역 안에서만 스크롤) ──────┐ │
│ │ ☑ Card   채움 색 → color/bg/surface   │ │
│ │   ☑ Title 글자 크기 → font-size/body  │ │
│ └─────────────────────────────────────┘ │
│ ✓ 18개 연결 · 건너뜀 4 · 변수 탭에서 보기 → │  ← 연결 후
└────────────────────────────────────────┘
```

- **남는 것**
  - 미리보기, 후보 트리(체크박스), 선택한 항목에 연결, 진행률·취소(`#applyProgress`), 건너뜀 사유 칩
  - 레이어 머리를 누르면 캔버스에서 선택
  - 연결할 변수가 없을 때의 경고와 "토큰 만들기로 →"(`prereq.gotoCreate` 문구도 이것으로)
  - **변수 이름 필터(`#bindFilter`)**: `#bindViewRow`에서 꺼내 미리보기 트리 바로 위로 옮긴다. 미리보기가 있을 때만 보인다.
- **없애는 것**
  - "연결 현황" 버튼과 자동 연결 현황 조회, 흐리게 하던 대기 처리
  - 연결 현황 모드("=" 줄)와 연결 후 결과 트리
  - `#bindViewRow`의 나머지와 "변수 관리에서 보기" 버튼
- **후보 트리**는 목록 영역 안에서만 스크롤한다. 높이는 510에서 남는 만큼이다.
- **연결 후:** "✓ {n}개 연결 · 건너뜀 {m} · 변수 탭에서 보기 →" 한 줄과 사유 칩만 남는다.
- **"변수 없는 값 찾기"로 들어올 때**
  - 같은 선택의 미리보기 결과가 이미 있으면 다시 실행하지 않고 화면만 보여 준다.
  - 미리보기나 연결이 실행 중이면 화면만 보여 준다.
  - 연결할 변수가 없으면(`hasBindable=false`) 미리보기를 보내지 않고 지금의 경고를 보여 준다.
  - 위 셋이 아니면 `APPLY{preview:true}`를 보낸다.
- **텍스트 스타일 "기존 스타일 연결"**
  - 만들기 › 타이포에서 옮겨 온다(`APPLY_TEXT_STYLES`). 연결 카드 머리 아래 한 줄이다.
  - **무료:** `code.ts`의 `APPLY_TEXT_STYLES` 분기에서 `requireTextStyles` 검사를 지우고 UI 잠금도 푼다. 등록(`CREATE_TEXT_STYLES`)은 계속 유료다.
  - 등록된 텍스트 스타일이 없으면 `aria-disabled`로 두고 "등록된 텍스트 스타일이 없어요 · 타이포에서 등록 →(유료)"를 보여 준다.
- **선택이 없을 때:** 버튼은 `aria-disabled`이고, 누르면 "선택이 없어요 — 캔버스에서 레이어를 선택하세요"가 뜬다.

### 4.7 레이어 탭 — 이름, 컴포넌트

- 지금 적용 탭의 두 단계를 그대로 옮긴다. 기능은 바뀌지 않는다.
- 단계 레일(`#applyRail`)을 밑줄 하위 탭으로 바꾼다.
- 연결 카드의 "다음 →"(`.step[data-apply-step] .btn-next`)를 없앤다. 세 작업은 순서가 없다.
- 미리보기·스캔 트리는 목록 영역 안에서만 스크롤한다.
- `pipeline.indep` 문구 "…적용 탭에서" → "레이어 › 컴포넌트에서"

### 4.8 설정 탭

```
┌────────────────────────────────────────┐
│ 기본값                                  │
│  기준 크기 [16]px   이름 정리 깊이 [8]    │
│  격자 [8]px         허용오차 [0.5]px     │
├────────────────────────────────────────┤
│ 라이선스                                 │
│  [키 입력            ] [검증] [해제]      │
│  [ 결제 · 구독 관리 ↗ ]                  │  ← 외부 링크라 ↗
└────────────────────────────────────────┘
```

- **나가는 것:** 컬렉션 계층(→ 변수 탭 ⋯ 팝업), 코드로 내보내기(→ 변수 탭 ⋯ 팝업)
- **카피:** 기본값 안내 → "변수 만들기와 연결에 쓰는 값이에요"
- 선택 표시줄은 이 탭에서만 숨긴다.

### 4.9 최소화

```
펼친 상태                          최소화 상태 (400 × 48)
┌──────────────────────┐          ┌──────────────────────┐
│ [변수] 레이어 설정  — │   [—] →  │ (DSL)                │  ← 바 어디를 눌러도 펼침
│ …                    │   ← 클릭  └──────────────────────┘
└──────────────────────┘          실행 중: (DSL) 둘레 진행 테두리
                                   끝: (DSL)✓  또는 (DSL)⚠
```

- **마크:** "DSL" 700 굵기, `--accent-strong`(#0a6dbf) 바탕에 흰 글자(대비 5.31:1), 둥근 사각형. 라이트 기준.
  - 로고 파일이 생기면 바꾼다(커뮤니티 에셋 파일의 `icon-128` 프레임).
- **진행 테두리를 그리는 때:** 아래 메시지를 보내고 결과가 올 때까지.
  - `APPLY`, `APPLY_SELECTED`, `APPLY_TEXT_STYLES`, `RENAME_APPLY`, `CREATE_TOKENS`, `CREATE_SEMANTICS`, `GENERATE_DARK_MODE`, `CREATE_TEXT_STYLES`, `REGISTER_COMPONENTS`, `COMPONENTIZE_SIMILAR`, `CLASSIFY_VARIANTS`, `GENERATE_MISSING_VARIANTS`, 마법사 실행
  - 진행률이 있으면(연결) 그 비율만큼 그리고, 없으면 회전으로 그린다.
- **끝난 뒤 (⑧)**
  - 성공: 마크 오른쪽 아래에 ✓가 3초간 보인다.
  - 실패(오류 응답): ⚠가 펼칠 때까지 남는다.
  - 최소화 중 선택이 바뀌어 미리보기가 버려지면 테두리만 멈추고 표시는 남기지 않는다.
- **동작**
  - 바를 누르거나 Enter/Space를 누르면 510으로 펼쳐진다. 보던 탭, 하위 화면, 스크롤은 유지되고, 포커스는 [—]로 간다.
  - 펼친 뒤 다시 읽기(§4.1)가 1번 일어난다. 최소화 상태에서 포인터가 들어오는 것으로는 다시 읽지 않는다.
  - 마우스를 올리면 "펼치기"가 뜬다. 접근성 이름은 "펼치기"이고, 진행 중이면 "펼치기 · 작업 중", 실패면 "펼치기 · 실패한 작업 있음"이다.
  - 최소화할 때 열린 메뉴·팝업·팝오버는 닫는다. 실행 중인 작업은 계속 돈다.
- **다시 열 때:** 최소화는 기억하지 않는다. 항상 400×510으로 연다.
- **크기 근거:** 피그마 플러그인 창은 최소 너비 70, 최소 높이 0이다(`plugin-typings` `showUI` 설명, 사실).

- `manifest.json`에 `teamlibrary` 권한이 없다. 그래서 라이브러리 **전체 목록**은 가져올 수 없고, 연결된 것만 보인다.

### 12.2 레이어 변경 감지(`nodechange`) — 검증 불가, 설계에서 제외

- 검증용 새 파일 `DSL 검증용 — nodechange (삭제 가능)`(kahee 팀 Drafts, `jAUKqpnfBLzMAHIzNzhNR9`)에서 시도했다.
- 결과: 피그마 연결 도구(MCP) 실행 환경에서 `PAGE 노드에 'on' 속성 없음` 오류가 났다. `documentchange`는 이 도구에서 금지된 `loadAllPagesAsync`가 필요하다.
- 결론: 쓰지 않는다. 검증용 파일은 지워도 된다.
