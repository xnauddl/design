## 1. 왜 바꾸나 (문제)

1. **나누는 기준이 섞여 있었다.** 시작은 "처음 쓰는 사람", 만들기·적용은 "작업 순서", [변수]는 "대상", 설정은 "기타"였다. "변수를 보고 싶다"는 목적 하나에 갈 곳이 3곳이었다.
   - 피드백 1: "이미 변수가 있는데 '만들기'에 들어가 없다는 걸 확인한 뒤 '적용'으로 이동했다."
   - 피드백 2: "무엇이 어디에 연결됐는지 알 수 없다."
   - 피드백 3: "[변수]가 적용 탭 안에서 열리는 건가?"
2. **우회로가 계속 늘었다.** 기존 변수 배너 2개, 연결 카드 → 변수 관리 링크가 그 예다. 기준이 섞여서 생긴 문제를 덮는 패치였다.
3. **같은 데이터를 두 번 그렸다.** 연결 카드의 "연결 현황"과 변수 관리의 "사용처"는 같은 조회 함수(`scanBindings`)를 쓴다.
4. **노트북 화면을 너무 가렸다.** 13인치 화면(1470×956 가정)에서 400×660 창은 높이의 약 75%를 가린다. 510이면 약 58%, 최소화하면 약 5%다(추정).
5. **역할이 사용자 의도와 반대였다.** 플러그인은 레이어 연결을 바꾸는 기능(교체)은 있었지만 변수 자체는 고칠 수 없었다. 사용자가 정한 역할은 이렇다: **플러그인 = 쓰인 변수를 보고 변수를 고치는 도구, 레이어에 붙은 변수를 바꾸는 일 = 피그마.**

## 2. 원칙

1. **탭 = 다루는 대상.**
   - **변수 탭:** 파일의 변수를 보고 만든다(고치기는 다음 PR). 단, 변수를 **만드는 일(시작 화면, 만들기)은 선택한 레이어를 읽어서** 동작한다. 그래서 이 두 화면에는 선택 표시줄이 필요하다.
   - **레이어 탭:** 지금 선택한 레이어에 변수를 붙이고, 이름을 정리하고, 컴포넌트로 만든다.
   - **설정 탭:** 자주 안 바꾸는 값과 라이선스.
2. **보기는 변수 탭, 붙이는 작업은 레이어 탭.** 이미 연결된 상태는 변수 탭에서만 보여 준다.
3. **유료/무료는 탭이 아니라 버튼에서 표시한다.** 있는 자산을 쓰는 일은 무료, 새로 만드는 일은 유료다.
4. **변수 관리 범위.**
   - v3: 보기, 복사, 사용 레이어 선택, 상세(읽기)
   - 다음 PR: 별칭 대상 바꾸기, 이름 바꾸기, 값 고치기. 2026-08-06 "변수 편집기 제거"를 번복한다.
   - **하지 않음:** 변수 삭제, 레이어 연결 일괄 교체
   - 변수 삭제를 하지 않는 이유: 이 파일을 라이브러리로 쓰는 다른 파일의 연결이 끊긴다. 파일 안에서는 ⌘Z로 되돌릴 수 있어도, 다른 파일에서 끊긴 연결은 되돌아오지 않는다.
5. **400×510 화면 규칙.**
   - 버튼은 카드 제목 바로 아래, 목록보다 위에 둔다. 지금 구조(v2 "적용 버튼 상단")를 유지하고 sticky는 쓰지 않는다.
   - 각 화면 **첫 카드**의 주 버튼은 스크롤 없이 보인다.
   - 긴 목록(미리보기 트리, 변수 목록)은 목록 영역 안에서만 스크롤한다. 페이지 전체 가로 스크롤은 0이다.
6. **상태 기억.** 플러그인이 열려 있는 동안 각 탭은 마지막 하위 화면, 단계, 스크롤 위치를 기억한다. 플러그인을 다시 열면 모두 처음 상태로 돌아간다.

## 3. 전체 구조

```
플러그인 (400 × 510 · 최소화 400 × 48)
├─ 탭 바: [변수] [레이어] [설정]                                     [—] 최소화
│
├─ 변수 (기본 탭)
│   ├─ (로컬 변수 0개일 때) 시작 화면              ※ 선택 표시줄 보임
│   │    ├─ 한 번에 정리 (마법사)
│   │    ├─ 준비 현황 (7단계 목록, 줄을 누르면 해당 단계로)
│   │    └─ "색부터 하나씩 만들기 →"
│   ├─ 변수 목록 (로컬 변수가 있을 때 기본)         ※ 선택 표시줄 없음 (머리줄이 대신함)
│   │    ├─ 머리줄 1: 연결 N · 레이어 M                      [+ 만들기] [⋯]
│   │    ├─ 머리줄 2: 준비 현황 n/7 ▾          안 붙은 값 찾기 →
│   │    ├─ 칩: [모두] (Global G 24)(Semantic S 12)(Color LIB 1) …   🔍
│   │    ├─ 목록: 그룹 머리(접기) → 변수 행 (이름 · 값 · 사용 수)
│   │    │        쓰는 변수 = 강조 + 사용 수 · 안 쓰는 변수 = 흐리게
│   │    ├─ 우클릭/⋯ 메뉴: 이름 복사 · 값 복사 · CSS 변수명 복사 · 사용 레이어 선택 · 상세
│   │    └─ [⋯] 메뉴: 컬렉션 역할 지정… · 코드로 내보내기…
│   └─ 만들기 (하위 화면, "← 변수 목록"으로 복귀)   ※ 선택 표시줄 보임
│        ├─ 맨 위: 한 번에 정리 (마법사, 접힘)
│        └─ 4단계: 색 → 토큰(간격·크기 + 시맨틱 매핑) → 테마(다크) → 타이포(텍스트 스타일)
│
├─ 레이어                                           ※ 선택 표시줄 보임
│   ├─ 하위 탭: [연결] [이름] [컴포넌트]   (순서가 있는 단계가 아니라 번호 없음)
│   ├─ 연결: 미리보기 → 후보 트리(체크) → 선택한 항목에 연결
│   │        → 결과 요약 + 건너뛴 사유 칩 + "변수 탭에서 보기"
│   │        + 텍스트 스타일: [기존 스타일 연결] (무료)
│   ├─ 이름: 미리보기 → 이름 적용 · 잠금 제외
│   └─ 컴포넌트: 후보 스캔 · 닮은 스캔 · 등록 · 묶기 · 베리언트 분류 · 누락 조합 생성
│
└─ 설정                                             ※ 선택 표시줄 없음
    ├─ 기본값 (기준 크기 · 이름 정리 깊이 · 격자 · 허용오차)
    └─ 라이선스
```

### 선택 표시줄이 보이는 곳

| 화면 | 선택 표시줄 | 이유 |
|---|---|---|
| 변수 › 시작 화면 | **보임** | 마법사가 선택한 화면을 읽음 |
| 변수 › 목록 | 없음 | 머리줄 "연결 N · 레이어 M" 또는 "선택 없음"이 대신함 |
| 변수 › 만들기 | **보임** | 색 추출, 토큰 미리보기, 텍스트 스타일 스캔이 선택을 읽음 |
| 레이어 (3개 하위 탭 모두) | **보임** | 선택한 레이어가 작업 대상 |
| 설정 | 없음 | 선택과 무관 |

### 화면 사이 이동 (전부)

| 출발 | 도착 | 언제 |
|---|---|---|
| 변수 › 목록 "안 붙은 값 찾기 →" | 레이어 › 연결 (미리보기 자동 실행) | 선택한 레이어에서 아직 변수가 안 붙은 값을 찾을 때 |
| 변수 › 목록 "준비 현황 ▾" 줄 | 변수 › 만들기 해당 단계 / 레이어 › 연결·이름 | 다음에 할 일을 고를 때 (지금의 `gotoStep`) |
| 변수 › 시작 화면 "색부터 만들기 →" | 변수 › 만들기 › 색 | 하나씩 만들 때 |
| 변수 › 만들기 마지막 단계 | 변수 › 목록 / 레이어 › 연결 | 만들기를 마쳤을 때 |
| 변수 › 상세 "사용 레이어 선택" | 캔버스 선택 (탭 이동 없음) | 변수를 쓰는 레이어를 볼 때 |
| 레이어 › 연결 "변수 탭에서 보기 ↗" | 변수 › 목록 | 연결 결과를 확인할 때 |
| 레이어 › 연결 "토큰 만들기로 →" | 변수 › 만들기 › 토큰 | 연결할 변수가 없을 때 (지금의 `goToCreate`) |
| 레이어 › 연결 "타이포에서 등록 →" | 변수 › 만들기 › 타이포 | 기존 스타일 연결을 누르려는데 등록된 텍스트 스타일이 없을 때 |

**없애는 이동:** 기존 변수 배너 2개(`goToBindStatus`, `goToCollectionRoles`), 시작 탭으로 가는 첫 화면 지정.

## 4. 화면별 상세

글자 와이어프레임은 폭 400, 높이 510 기준이다. 픽셀까지 맞추는 것이 목표가 아니라 배치와 우선순위를 정하는 용도다.

### 4.1 공통 셸

```
┌────────────────────────────────────────┐
│ [ 변수 ]  레이어   설정              —  │  ← 탭 바 (sticky) · 오른쪽 끝 최소화
├────────────────────────────────────────┤
│ ● 프레임 1 · 하위 42                     │  ← 선택 표시줄 (§3 표의 화면에서만)
├────────────────────────────────────────┤
│                탭 내용                  │
└────────────────────────────────────────┘
```

- 탭은 3개이고, 키보드 화살표로 이동한다(기존 roving tabindex 유지).
- [변수] 버튼, "← 돌아가기", ↕ 높이 전환은 없앤다.

### 4.2 변수 탭 — 시작 화면 (로컬 변수 0개)

```
┌────────────────────────────────────────┐
│ ● 선택 없음                              │
│ 로컬 변수 없음                  [LIB 4]  │  ← 라이브러리 연결이 있을 때만 태그
│ ┌ 한 번에 정리 ───────────────────────┐ │
│ │ 선택한 화면의 색·간격을 변수로 만들고  │ │
│ │ 붙입니다                            │ │
│ │ ☑ 역할 매핑🔒 ☐ 다크🔒 ☐ 텍스트 스타일🔒│ │
│ │ 프레임을 선택하세요       [전체 실행]  │ │  ← 선택 없으면 비활성 + 안내
│ └─────────────────────────────────────┘ │
│ 준비 현황 0/7 ▾                          │
│ 하나씩 하려면  [ 색부터 만들기 → ]        │
└────────────────────────────────────────┘
```

- **보이는 조건:** 로컬 변수가 0개일 때(`PREREQ_STATE`의 `tierVars + otherVars === 0`).
- **라이브러리 변수:** 선택 안에 라이브러리 변수 연결이 있으면 제목 옆에 `LIB n` 태그를 붙인다. 태그를 누르면 변수 목록(라이브러리 변수만)으로 간다.
- **전체 실행:** 선택이 없으면 비활성이고, 버튼 옆에 "프레임을 선택하세요"를 미리 보여 준다.
- **준비 현황:** 지금 시작 탭의 7단계 목록(색, 토큰, 역할 매핑, 다크, 텍스트 스타일, 연결, 이름)이다. 접어서 둔다.
- 변수가 생기면 다음에 이 탭에 들어올 때 변수 목록으로 바뀐다. 실행 중에는 화면을 바꾸지 않는다.
- 마법사가 끝나면 완료 문구에 [변수 목록 보기] 버튼을 둔다.
- "다시 보지 않기"(온보딩 숨김)는 없앤다.

### 4.3 변수 탭 — 변수 목록 (기본)

```
┌────────────────────────────────────────┐
│ 연결 18 · 레이어 7          [+ 만들기] [⋯] │  ← 선택 없으면 "선택 없음"
│ 준비 현황 5/7 ▾        안 붙은 값 찾기 → │
│ [모두](Global G 24)(Semantic S 12)(Colo› │  ← 칩 줄, 넘치면 옆으로 밀기
│ 🔍 이름 검색                              │
│ 이름                값 Light ▾    사용   │  ← 보이는 모드가 2개 이상일 때만 ▾
│ ▾ Semantic · color/bg           2       │  ← 그룹 머리 (쓰는 변수가 있으면 펼침)
│    ■ surface        → gray/50      12   │  ← 쓰는 변수: 강조
│    ■ raised         → gray/100     ·    │  ← 안 쓰는 변수: 흐리게
│ ▸ Global · color/gray           0       │
│ ▾ Color · Background/Danger  LIB  1     │
│    ■ Default  LIB   #EC221F         1   │
├────────────────────────────────────────┤
│ 상태 줄                                 │
└────────────────────────────────────────┘
```

**머리줄 1: 연결 N · 레이어 M**
- N = 선택 안의 연결 수, M = 연결이 하나라도 있는 레이어 수.
- 이미 있는 조회 결과(`BINDINGS_RESULT.total` / `boundNodes`, `forManager` 경로)로 센다.
- 조회 상한(`RESULT_CAP` 600)에 걸리면 "연결 600+ · 레이어 120+"로 표시한다.
- 선택이 없으면 "선택 없음"으로 표시한다.

**머리줄 2**
- "준비 현황 n/7 ▾": 누르면 7단계 목록이 펼쳐지고, 줄을 누르면 해당 단계로 간다.
- "안 붙은 값 찾기 →": 레이어 › 연결로 가서 미리보기를 자동 실행한다. 선택이 없으면 비활성이다.

**칩 줄**
- [모두]가 항상 기본이다. 컬렉션 칩은 하나만 걸러 볼 때 쓴다.
- 칩 표기는 이름 + 역할 배지(G/S/C, 역할이 없으면 "?", 라이브러리는 `LIB`) + 변수 수다.
- 칩이 넘치면 칩 줄 안에서만 가로로 민다.
- 역할 배지를 누르면 "컬렉션 역할 지정" 팝업이 열린다(지금 설정 탭 카드 내용 그대로). 라이브러리 컬렉션 칩에는 역할 배지가 없다.

**목록**
- 항상 **전체 변수**를 보여 준다. "쓰는 것만" 토글은 없다.
- 그룹 경로마다 머리 한 줄을 둔다(`groupRows`). [모두]일 때는 머리에 컬렉션 이름을 붙인다. 예: `Semantic · color/bg`
- 그룹은 중첩하지 않고 들여쓰지 않는다.
- **펼침 규칙**
  - 선택이 있으면: 쓰는 변수가 있는 그룹만 펼치고 나머지는 접는다.
  - 선택이 없으면: 그룹이 10개 이하면 모두 펼치고, 넘으면 모두 접는다.
  - 사용자가 직접 펼치거나 접은 그룹은 플러그인이 열려 있는 동안 그 상태를 유지한다.
- **강조 규칙**
  - 선택 안에서 쓰는 변수: 기본 글자색 + 사용 수.
  - 안 쓰는 변수: 흐리게(사용 수 자리 "·").
  - 그룹 머리에는 쓰는 변수 수를 표시한다.
- **열:** 이름(마지막 토막), 값, 사용 수.
- **값 열과 모드**
  - 값 열 머리의 ▾에 보이는 컬렉션들의 모드 이름을 모은다(예: Light, Dark, SDS Light).
  - 고른 모드가 없는 컬렉션은 기본(첫) 모드 값을 보여 준다.
  - 보이는 모드가 1개뿐이면 ▾를 숨긴다.
  - 모든 모드를 한 번에 보려면 상세 팝업을 연다.
- **별칭:** 별칭은 알약으로 표시한다(`→ gray/50`). 색 견본은 별칭을 따라가 실제 색을 보여 준다.
  - 알약을 누르면 그 변수로 이동한다: 칩을 [모두]로 바꾸고 → 검색어를 지우고 → 그룹을 펼치고 → 그 행에 포커스.
- **라이브러리 변수**
  - 실제 이름 + `LIB` 태그로 표시한다.
  - 이름은 `getVariableByIdAsync`로 찾는다(§11 검증).
  - 로컬 목록에는 없으므로 **선택 안에 연결된 것만** 목록에 나온다.
- **검색:** 이름에 포함된 글자로 찾는다. 칩으로 거른 범위 안에서만 찾는다.

**선택이 바뀔 때**
- 400ms 기다렸다가 반영한다. 레이어를 연달아 누를 때 깜빡이지 않게 하기 위해서다.
- 펼침과 강조만 바뀌고, 목록 내용(전체 변수)은 바뀌지 않는다.
- 보던 행(포커스, 상세를 연 행)은 화면에 계속 보이게 한다. 열린 상세 팝업은 닫지 않는다.
- 사용 수 조회(`SCAN_BINDINGS{forManager}`)는 **변수 목록이 보일 때만** 보낸다. 다른 탭이나 만들기 화면, 최소화 상태에서는 보내지 않는다. 목록으로 돌아오면 한 번 보낸다.

**메뉴**
- 우클릭/⋯ 메뉴: 이름 복사 · 값 복사 · CSS 변수명 복사 · 사용 레이어 선택 · 상세
  - 사용 레이어 선택은 선택 안 사용 수가 0이면 비활성이다. 보조 문구 "선택한 레이어 안에서 찾습니다"를 붙인다.
  - **교체, 이름 변경, 삭제는 없다.**
- [⋯] 메뉴
  - 컬렉션 역할 지정…
  - 코드로 내보내기…: 팝업 안에서 형식(W3C/CSS), 폰트 단위(px/rem)를 고르고 [내보내기]를 누른다.

**[+ 만들기]:** 만들기 하위 화면(4.4)으로 바로 간다.

### 4.4 변수 탭 — 만들기 (하위 화면)

```
┌────────────────────────────────────────┐
│ ● 프레임 1 · 하위 42                     │
│ ← 변수 목록                              │
│ ▸ 한 번에 정리 (마법사)                   │  ← 접힘. 펼치면 4.2와 같은 카드
│ (1 색)─(2 토큰)─(3 테마)─(4 타이포)       │  ← 기존 단계 레일
├────────────────────────────────────────┤
│ 카드 제목            [미리보기][적용][다음→]│  ← 버튼은 제목 아래 툴바 (지금 그대로)
│ (지금 만들기 탭의 각 단계 카드 그대로)      │
└────────────────────────────────────────┘
```

- 지금 만들기 탭의 4단계를 그대로 옮긴다. 카드, 미리보기, 잠금 모두 같다.
- 타이포 단계의 "기존만 연결" 버튼은 레이어 › 연결로 옮긴다(4.5).
- 토큰 단계는 카드가 2개(간격·크기, 시맨틱 매핑)다. 두 번째 카드의 버튼은 510에서 스크롤해야 보인다. 이것은 받아들인다. 준비 현황에서 "역할 매핑"을 누르면 그 카드로 바로 스크롤한다.
- 마지막 단계에는 출구 두 개를 둔다: "변수 목록에서 보기", "레이어에 붙이기 →".
- "← 변수 목록"으로 돌아오면 변수 목록을 다시 불러온다(`GET_VAR_TABLE`).

### 4.5 레이어 탭 — 연결

```
┌────────────────────────────────────────┐
│ ● 프레임 1 · 하위 42                     │
│ [ 연결 ]  이름   컴포넌트                 │
├────────────────────────────────────────┤
│ 변수 붙이기   [미리보기][선택한 항목에 연결]│  ← 버튼은 목록 위 (지금 그대로)
│ 후보 18 · 건너뜀 4                       │
│ [값이 다름 3] [잠김 1]                   │
│ ☑ Card     채움 색 → color/bg/surface   │
│   ☑ Title  글자 크기 → font/size/lg     │
│ ...                                     │
│ ─ 연결 후 ─                              │
│ ✓ 18개 연결 · 건너뜀 4  변수 탭에서 보기 ↗ │
├────────────────────────────────────────┤
│ 텍스트 스타일  같은 모양의 기존 스타일에 연결 │
│                     [ 기존 스타일 연결 ]  │
└────────────────────────────────────────┘
```

- **남는 것**
  - 미리보기, 후보 트리(체크박스), 선택한 항목에 연결
  - 진행률과 취소, 건너뛴 사유 칩
  - 레이어 머리를 누르면 캔버스에서 그 레이어를 선택하는 동작
  - 연결할 변수가 없을 때의 경고와 "토큰 만들기로 →"
- **없애는 것**
  - "연결 현황" 버튼과 자동 연결 현황 조회
  - 조회를 기다리는 동안 흐리게 하던 처리
  - 연결 현황 모드("=" 줄)와 연결 후 결과 트리
  - 보기 필터 줄(`#bindViewRow`), "변수 관리에서 보기" 버튼
- **연결 후:** 숫자 요약, 건너뛴 사유 칩, "변수 탭에서 보기 ↗"만 남긴다.
- **"안 붙은 값 찾기"로 들어온 경우:** 이 화면으로 오면서 미리보기를 바로 보낸다(`APPLY{preview:true}`).
- **텍스트 스타일 "기존 스타일 연결"**
  - 만들기 › 타이포에서 옮겨 온다(`APPLY_TEXT_STYLES`, 스캔 표와 무관하게 동작).
  - **무료로 바꾼다:** `code.ts`의 `requireTextStyles` 검사와 UI 잠금을 없앤다.
  - 등록된 텍스트 스타일이 없으면 버튼을 비활성으로 두고 "타이포에서 등록 →"를 보여 준다.
- **선택이 없을 때:** "레이어를 선택하세요"를 보여 주고 버튼은 비활성이다.

### 4.6 레이어 탭 — 이름, 컴포넌트

- 지금 적용 탭의 두 단계를 그대로 옮긴다. 기능은 바뀌지 않는다.
- 레일을 하위 탭으로 바꾸므로 번호(①②③)와 "다음 →"를 없앤다.

### 4.8 최소화

```
펼친 상태                          최소화 상태 (400 × 48)
┌──────────────────────┐          ┌──────────────────────┐
│ [변수] 레이어 설정  — │   [—] →  │ (DSL)                │  ← 바 어디를 눌러도 펼침
│ …                    │   ← 클릭  └──────────────────────┘
└──────────────────────┘                실행 중: (DSL) 둘레에 진행 테두리
```

- **모양**
  - "DSL" 글자 마크만 보인다. 굵은 글씨를 둥근 사각형 배지에 넣고, 플러그인 강조색을 쓴다. 다크 테마에서도 읽혀야 한다.
  - 플러그인 이름과 닫기 버튼은 피그마가 창 위에 붙여 주는 머리줄에 있다.
  - 로고 파일이 생기면 글자 마크를 바꾼다(커뮤니티 에셋 파일의 `icon-128` 프레임).
- **진행 표시**
  - 미리보기, 연결, 마법사, 만들기가 실행 중이면 마크 둘레에 얇은 진행 테두리가 돈다. 끝나면 사라진다.
  - 그 밖에는 아무것도 표시하지 않는다.
- **동작**
  - 바를 누르거나 Enter/Space를 누르면 510으로 펼쳐진다. 보던 탭, 하위 화면, 스크롤은 유지한다.
  - 마우스를 올리면 "펼치기"가 뜬다. 접근성 이름도 "펼치기"다.
  - 최소화할 때 열린 팝업과 우클릭 메뉴는 닫는다.
  - 실행 중인 작업은 계속 돈다.
- **다시 열 때:** 최소화는 기억하지 않는다. 항상 400×510으로 연다.
- **크기 근거:** 피그마 플러그인 창은 최소 너비 70, 최소 높이 0이다(`plugin-typings` `showUI` 설명, 사실). 400×48은 허용된다. 너비를 400으로 두면 펼칠 때 너비가 바뀌지 않는다.

## 5. 기능 이동표 (지금 → v3)

| 기능 | 지금 | v3 | 변화 |
|---|---|---|---|
| 한 번에 정리(마법사) | 시작 | 변수 › 시작 화면 + 변수 › 만들기 맨 위 | 위치. 선택 없으면 미리 비활성 |
| 준비 현황 (7단계, 누르면 이동) | 시작 | 변수 › 시작 화면 + 변수 목록 머리줄 "준비 현황 ▾" | 위치. 접어서 둠 |
| 기존 변수 배너 2개 | 시작, 만들기 | — | **삭제** |
| 온보딩 "다시 보지 않기" | 시작 | — | **삭제** (조건부 표시로 대체) |
| 색 · 토큰 · 시맨틱 · 다크 · 텍스트 스타일 등록 | 만들기 | 변수 › 만들기 | 위치 |
| 텍스트 스타일 "기존만 연결" | 만들기 › 타이포 (유료) | 레이어 › 연결 (**무료**) | 위치, 요금제 |
| 변수 연결 미리보기·연결 | 적용 › 연결 | 레이어 › 연결 | 위치 |
| 연결 현황(보기, 자동 조회) | 적용 › 연결 | — (변수 목록의 강조와 사용 수가 대신함) | **삭제** |
| 연결 결과 트리 | 적용 › 연결 | 요약 한 줄 + 사유 칩 + 링크 | 축소 |

**새로 넣을 항목**

- 셸
  - 처음 열면 변수 탭이 활성이다.
  - 시작할 때 `SET_UI_SIZE`가 400×510을 요청하고, 탭을 바꿔도 크기 요청은 0회다.
  - 선택 표시줄은 §3 표대로 보이고 숨는다(시작 화면 · 만들기 · 레이어에서 보임, 목록 · 설정에서 숨음).
  - 510 높이에서 각 화면 첫 카드의 주 버튼이 스크롤 없이 보인다.
  - 탭을 오가면 하위 화면과 단계가 유지된다.
- 시작 화면
  - 로컬 변수 0개면 시작 화면, 1개 이상이면 변수 목록이 보인다.
  - 선택이 없으면 "전체 실행"이 비활성이고 안내가 보인다.
- 변수 목록
  - [모두]가 기본이고, 컬렉션 칩을 누르면 그 컬렉션만 남는다.
  - 선택이 있으면 쓰는 변수의 그룹만 펼쳐지고, 쓰는 행은 강조, 안 쓰는 행은 흐리게 보인다.
  - 선택을 빠르게 3번 바꿔도 `SCAN_BINDINGS{forManager}`는 1번만 보낸다(400ms 지연).
  - 변수 목록이 안 보일 때(레이어 탭, 최소화) 선택을 바꿔도 조회 요청은 0회다.
  - 관리용이 아닌 `SCAN_BINDINGS` 요청은 언제나 0회다.
  - 보이는 모드가 1개면 값 열 머리에 ▾가 없다.
  - 머리줄에 "연결 N · 레이어 M"이 보이고, 상한에 걸리면 "+"가 붙는다.
  - "준비 현황 ▾"을 펼치고 줄을 누르면 해당 단계로 간다.
  - "안 붙은 값 찾기 →"를 누르면 레이어 › 연결이 열리고 `APPLY{preview:true}`가 나간다.
  - 원격 변수(모의 데이터 `remote: true`)는 이름 + `LIB` 태그로 보이고 "(삭제된 변수)"가 아니다.
  - 메뉴에 교체, 이름 변경, 삭제가 없다.
- 레이어 탭
  - 연결 후 "변수 탭에서 보기"를 누르면 변수 목록이 열린다.
  - 기존 텍스트 스타일 연결 버튼은 Free 티어에서도 잠기지 않는다.
  - 등록된 텍스트 스타일이 없으면 "타이포에서 등록 →"이 보인다.
- 설정
  - 설정 탭에 컬렉션 계층과 내보내기가 없고, ⋯ 메뉴에서 두 팝업이 열린다.
- 최소화
  - 최소화하면 `SET_UI_SIZE`가 `mini`를 요청하고 "DSL" 마크만 보인다.
  - 바를 누르면 510으로 돌아가고 보던 탭이 유지된다.
  - `mini`는 저장되지 않는다.
  - 최소화할 때 열린 팝업은 닫힌다.
  - 실행 중이면 진행 테두리가 보인다.

### 라이브러리 변수 이름 조회 (2026-11-03, 읽기 전용)
