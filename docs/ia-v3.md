## 1. 왜 바꾸나 (문제)

1. **나누는 기준이 섞여 있었다.** 시작은 "처음 쓰는 사람", 만들기·적용은 "작업 순서", [변수]는 "대상", 설정은 "기타" 기준이었다. 그래서 "변수를 보고 싶다"는 목적 하나에 갈 수 있는 곳이 3곳이었다.
   - 실제 피드백: "이미 변수가 있는데 '만들기'에 들어가 없다는 걸 확인한 뒤 '적용'으로 이동했다." "무엇이 어디에 연결됐는지 알 수 없다." "[변수]가 적용 탭 안에서 열리는 건가?"
2. **우회로가 계속 늘었다.** 기존 변수 배너 2개, 연결 카드 → 변수 관리 링크, 탭 이동 6곳은 모두 기준이 섞여 생긴 문제를 덮는 패치였다.
3. **같은 데이터를 두 번 그렸다.** 연결 카드의 "연결 현황"과 변수 관리의 "사용처"는 같은 조회 함수(`scanBindings`)를 쓴다.
4. **너비가 탭에 따라 바뀌었다.** [변수]만 760이고 나머지는 400이라 창이 들썩였다.

## 2. 원칙

1. **탭 = 다루는 대상.**
   - **변수 탭:** 파일의 변수와 스타일을 보고, 만들고, 고친다. 선택과 무관하게 의미가 있다.
   - **레이어 탭:** 지금 선택한 레이어를 고친다(변수 붙이기, 이름, 컴포넌트). 선택이 없으면 할 일이 없다.
   - **설정 탭:** 자주 안 바꾸는 값과 라이선스.
2. **보기는 변수 탭, 붙이는 작업은 레이어 탭.** 이미 연결된 상태는 변수 탭에서만 보여 준다. 레이어 탭은 "무엇을 붙일지 고르고 붙이는" 작업만 맡는다.
3. **유료/무료는 탭이 아니라 버튼에서 표시한다.** 기준은 그대로다(있는 자산을 쓰는 일 = 무료, 새로 만드는 일 = 유료). 변수 탭에 무료(관리)와 유료(만들기)가 섞이므로 잠금은 버튼마다 붙인다. 지금도 버튼 단위로 잠그므로 방식은 같다.
4. **이전 원칙 수정.** v2의 "플러그인은 변수 CRUD 앱이 아니다(값·이름 수정은 Figma Variables에 맡김)"는 2026-10 변수 관리 도입으로 이미 일부 번복됐다(ROADMAP P3). v3에서 바꾸는 범위와 그대로 두는 범위는 다음과 같다.
   - **이름 변경, 교체 후 삭제:** 플러그인에서 한다.
   - **값 편집:** 계속 Figma Variables에 맡긴다.

## 3. 전체 구조

```
플러그인 (560 × 660, ↕ 860)
├─ 탭 바: [변수] [레이어] [설정]                                 ↕ 높이 전환
│
├─ 변수 (기본 탭)
│   ├─ (변수가 0개일 때) 시작 화면
│   │    ├─ 한 번에 정리 (마법사)
│   │    ├─ 준비 현황
│   │    └─ "색부터 하나씩 만들기 →" (만들기 › 색으로)
│   ├─ 변수 목록 (변수가 있을 때 기본)
│   │    ├─ 머리줄: 준비 현황 요약 · [+ 만들기] · [⋯]
│   │    ├─ 범위: 선택에서 쓰는 것만(기본) / 전체 · 검색
│   │    ├─ 왼쪽: 컬렉션·그룹 트리 (컬렉션 옆에 역할 배지 G/S/C)
│   │    ├─ 오른쪽: 변수 표 (모드별 값 · 사용 수)
│   │    ├─ 우클릭 메뉴: 복사 3종 · 사용 레이어 선택 · 상세 · 교체 · 이름 변경* · 교체 후 삭제*
│   │    └─ [⋯] 메뉴: 컬렉션 역할 지정… · 코드로 내보내기…
│   └─ 만들기 (하위 화면, "← 변수 목록" 으로 복귀)
│        ├─ 맨 위: 한 번에 정리 (마법사, 접힘)
│        └─ 4단계: 색 → 토큰(간격·크기 + 시맨틱 매핑) → 테마(다크) → 타이포(텍스트 스타일)
│
├─ 레이어 (선택 표시줄은 이 탭에서만 보임)
│   ├─ 하위 탭: [연결] [이름] [컴포넌트]   ※ 순서가 있는 '단계'가 아니므로 번호를 붙이지 않음
│   ├─ 연결: 미리보기 → 후보 트리(체크) → 선택한 항목에 연결 → 결과 요약 + 건너뛴 사유 칩 + "변수 탭에서 보기"
│   │        + 텍스트 스타일: [기존 스타일 연결]
│   ├─ 이름: 미리보기 → 이름 적용 · 잠금 제외
│   └─ 컴포넌트: 후보 스캔 · 닮은 스캔 · 등록 · 묶기 · 베리언트 분류 · 누락 조합 생성
│
└─ 설정
    ├─ 기본값 (기준 크기 · 이름 정리 깊이 · 격자 · 허용오차)
    └─ 라이선스
```

`*` 표시는 ROADMAP의 "변수 관리 P3"(미구현)입니다. v3 IA는 이 자리를 미리 잡아 둡니다.

## 4. 화면별 상세

글자 와이어프레임 기준 폭 560px입니다. 픽셀 복제가 목표가 아니라 배치와 우선순위를 정하는 용도입니다.

### 4.1 공통 셸

```
┌──────────────────────────────────────────────────────────────┐
│ [ 변수 ]  레이어   설정                               ↕       │  ← 탭 바 (sticky)
├──────────────────────────────────────────────────────────────┤
│ (레이어 탭에서만) ● 프레임 1개 · 하위 레이어 42개              │  ← 선택 표시줄
├──────────────────────────────────────────────────────────────┤
│                         탭 내용                               │
└──────────────────────────────────────────────────────────────┘
```

- 탭은 3개, 키보드 화살표로 이동한다(기존 roving tabindex 유지).
- [변수] 버튼과 "← 돌아가기"는 없앤다. 변수는 이제 탭이다.
- ↕ 높이 전환(660/860)은 유지한다. 너비 토글은 없다.

### 4.2 변수 탭 — 시작 화면 (변수 0개)

```
┌──────────────────────────────────────────────────────────────┐
│ 이 파일에는 아직 변수가 없어요                                   │
│                                                              │
│ ┌ 한 번에 정리 ────────────────────────────────────────────┐ │
│ │ 선택한 화면에서 색·간격을 뽑아 변수로 만들고 붙입니다      │ │
│ │ ☑ 역할 매핑 🔒  ☐ 다크 🔒  ☐ 텍스트 스타일 🔒            │ │
│ │                                         [ 전체 실행 ]     │ │
│ └──────────────────────────────────────────────────────────┘ │
│ ┌ 준비 현황 ───────────────────────────────────────────────┐ │
│ │ Global 0 · Semantic 0 · Component 0 · 텍스트 스타일 0      │ │
│ └──────────────────────────────────────────────────────────┘ │
│                                                              │
│ 하나씩 하고 싶다면  [ 색부터 만들기 → ]                        │
└──────────────────────────────────────────────────────────────┘
```

- **보이는 조건:** 로컬 변수가 0개일 때만 보인다(`PREREQ_STATE`의 `tierVars + otherVars === 0`).
- 변수가 생기면 다음에 이 탭에 들어올 때 변수 목록으로 바뀐다. 실행 중에는 화면을 바꾸지 않는다.
- 지금 시작 탭의 "다시 보지 않기"(온보딩 숨김)는 없앤다. 변수가 생기면 저절로 사라지기 때문이다.

### 4.3 변수 탭 — 변수 목록 (기본)

```
┌──────────────────────────────────────────────────────────────┐
│ G 24 · S 12 · C 0 · 선택 연결 18/30         [+ 만들기] [⋯]   │
│ 범위 [선택에서 쓰는 것만 · 레이어 3 ▾]   🔍 이름 검색          │
├────────────────┬─────────────────────────────────────────────┤
│ ▾ Global   G   │ 이름            Light      Dark     사용     │
│   ▸ color      │ ■ primary/500   #3B82F6    #60A5FA   12     │
│   ▸ spacing    │ ■ primary/600   #2563EB    #3B82F6    3     │
│ ▾ Semantic S   │ ...                                         │
│   ▸ bg         │                                             │
│ ▸ Brand (역할?)│                                             │
├────────────────┴─────────────────────────────────────────────┤
│ 상태 줄                                                      │
└──────────────────────────────────────────────────────────────┘
  트리 ≈ 170px · 표 ≈ 360px
```

- **머리줄**
  - 준비 현황을 한 줄로 요약한다(지금 시작 탭의 "준비 현황" 카드).
  - "선택 연결 18/30"은 선택 안의 연결 가능한 속성 중 연결된 수다. 계산 방식은 구현 때 확정한다(§11 미결 3).
- **범위**
  - 기본은 "선택에서 쓰는 것만"이다(기존 결정 유지).
  - 선택 표시줄이 없는 탭이므로, 선택 상태를 범위 컨트롤 안에 보여 준다("레이어 3"). 선택이 없으면 "선택 없음 — 전체 보기"로 표시한다.
- **트리**
  - 컬렉션 이름 옆에 역할 배지(G/S/C)를 붙인다. 역할이 없으면 "역할?"로 표시한다.
  - 배지를 누르면 "컬렉션 역할 지정" 팝업이 열린다. 지금 설정 탭 "컬렉션 계층" 카드 내용을 그대로 옮긴다.
- **표**
  - 기존 변수 관리 표를 그대로 쓴다.
  - 560px에서 모드가 3개 이상이면 표 안에서만 가로 스크롤한다. 페이지 전체 가로 스크롤은 0이어야 한다.
- **우클릭(또는 ⋯) 메뉴:** 기존 6개(복사 3종, 레이어 선택, 상세, 교체)에 P3 2개(이름 변경, 교체 후 삭제)를 더한다.
- **[⋯] 메뉴**
  - 컬렉션 역할 지정…
  - 코드로 내보내기…: 팝업 안에 형식(W3C/CSS)과 폰트 단위(px/rem) 선택, [내보내기] 버튼을 둔다.
- **[+ 만들기]:** 만들기 하위 화면(4.4)으로 이동한다. 메뉴로 펼치지 않고 바로 이동한다. 4단계가 순서를 가지고 있어서 레일에서 고르는 편이 낫기 때문이다.

### 4.4 변수 탭 — 만들기 (하위 화면)

```
┌──────────────────────────────────────────────────────────────┐
│ ← 변수 목록                                                   │
│ ▸ 한 번에 정리 (마법사)                                       │  ← 접힘. 펼치면 4.2와 같은 카드
│ (1 색) ─ (2 토큰) ─ (3 테마) ─ (4 타이포)                      │  ← 기존 단계 레일
├──────────────────────────────────────────────────────────────┤
│ (지금 만들기 탭의 각 단계 카드 그대로)                          │
│                                            [ 다음 → ]        │
└──────────────────────────────────────────────────────────────┘
```

- 지금 만들기 탭의 4단계 내용을 그대로 옮긴다. 카드, 미리보기, 잠금 모두 같다.
- **바뀌는 것 하나:** 타이포 단계의 "기존만 연결" 버튼을 레이어 › 연결로 옮긴다(4.5).
- 만들기를 마치면 마지막 단계에 "변수 목록에서 보기"와 "레이어에 붙이기 →"(레이어 › 연결로 이동) 두 출구를 둔다.
- 다크 단계의 "토큰 생성으로 →"는 같은 화면 안의 단계 이동이 된다. 탭 이동이 아니다.

### 4.5 레이어 탭 — 연결

```
┌──────────────────────────────────────────────────────────────┐
│ ● 프레임 1개 · 하위 레이어 42개                                │
│ [ 연결 ]  이름   컴포넌트                                      │
├──────────────────────────────────────────────────────────────┤
│ 변수 붙이기                                   [ 미리보기 ]    │
│ ─ 미리보기 후 ─                                               │
│ 후보 18 · 건너뜀 4 [값이 변수와 다름 3] [잠긴 레이어 1]         │
│ ☑ Card            채움 색 → color/bg/surface                 │
│   ☑ Title         글자 크기 → font/size/lg                    │
│ ...                                  [ 선택한 항목에 연결 ]   │
│ ─ 연결 후 ─                                                   │
│ ✓ 18개 연결 · 건너뜀 4 [사유 칩…]        변수 탭에서 보기 ↗    │
├──────────────────────────────────────────────────────────────┤
│ 텍스트 스타일   선택한 텍스트를 같은 모양의 기존 스타일에 연결      │
│                                       [ 기존 스타일 연결 ]    │
└──────────────────────────────────────────────────────────────┘
```

- **남는 것**
  - 미리보기, 후보 트리(체크박스), "선택한 항목에 연결", 진행률·취소, 건너뛴 사유 칩
  - 레이어 머리를 누르면 캔버스에서 그 레이어를 선택하는 동작
- **없애는 것**
  - "연결 현황" 버튼
  - 선택을 바꿀 때마다 도는 자동 연결 현황 조회(250ms debounce)
  - 대기 중 흐림 처리, 연결 현황 모드("=" 줄)
  - 연결 후 결과 트리
  - 보기 필터 줄(`#bindViewRow`), "변수 관리에서 보기" 버튼
- **연결 후:** 숫자 요약, 건너뛴 사유 칩, "변수 탭에서 보기 ↗"만 남긴다. 링크를 누르면 변수 탭이 "선택에서 쓰는 것만" 범위로 열린다.
- **텍스트 스타일 "기존 스타일 연결":** 만들기 › 타이포에서 옮겨 온다. 스캔 표와 상관없이 동작하는 버튼이라 옮겨도 기능이 바뀌지 않는다(`APPLY_TEXT_STYLES`). 유료 여부는 §11 미결 1을 본다.
- **선택이 없을 때:** "레이어를 선택하세요" 안내만 보이고 버튼은 비활성이다.

### 4.6 레이어 탭 — 이름, 컴포넌트

- 지금 적용 탭의 두 단계를 그대로 옮긴다. 기능 변화는 없다.
- 레일을 하위 탭으로 바꾸므로 번호(①②③)와 "다음 →"는 없앤다. 세 작업은 순서와 무관하다.

### 4.7 설정 탭

```
┌──────────────────────────────────────────────────────────────┐
│ 기본값   기준 크기 [16]px · 이름 정리 깊이 [8] · 격자 [8]px      │
│          허용오차 [0.5]px                                      │
├──────────────────────────────────────────────────────────────┤
│ 라이선스 [키 입력      ] [검증] [해제]   [결제 · 구독 관리]       │

```

- **나가는 것:** 컬렉션 계층(→ 변수 탭 팝업), 코드로 내보내기(→ 변수 탭 ⋯ 팝업)
- **카피 수정:** 기본값 안내 "만들기·적용 화면에는 안 보여요"를 "변수 만들기와 연결에 쓰는 값이에요"로 바꾼다.

## 7. 주요 흐름

**A. 처음 쓰는 파일 (변수 0)**
1. 플러그인을 연다 → 변수 탭 › 시작 화면
2. [전체 실행] → 마법사가 만들기·연결까지 진행 → 완료 문구의 "변수 목록 보기"를 누르면 변수 목록

**B. 이미 변수가 있는 파일 (가장 흔하다고 추정. QA #2에서 확인)**
1. 플러그인을 연다 → 변수 탭 › 변수 목록 ("선택에서 쓰는 것만")
2. 레이어를 선택한다 → 표가 그 레이어가 쓰는 변수로 좁혀진다. 이것으로 "무엇이 무엇에 연결됐나"에 답한다.
3. 안 붙은 값이 있으면 레이어 탭 › 연결 › 미리보기 → 연결 → "변수 탭에서 보기 ↗"

**C. 변수 하나를 다른 변수로 바꾸기**
- 변수 목록 › 우클릭 › 교체 → 팝업에서 대상 선택 → 적용

**D. 코드로 꺼내기**
- 변수 목록 › ⋯ › 코드로 내보내기 → 형식 선택 → 파일 저장

v2와 비교한 클릭 수는 다음과 같습니다(추정).

| 흐름 | v2 | v3 |
|---|---|---|
| B "연결 확인" | 열기 → 적용 탭 → (자동 현황) = 1클릭, 또는 [변수] = 1클릭 | **0클릭** (기본 화면) |
| D 내보내기 | 설정 탭 → 내보내기 = 2클릭 | ⋯ → 내보내기 → 확인 = 3클릭 (+1) |
