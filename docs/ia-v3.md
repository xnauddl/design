## 1. 왜 바꾸나 (문제)

1. **나누는 기준이 섞여 있었다.** 시작은 "처음 쓰는 사람", 만들기·적용은 "작업 순서", [변수]는 "대상", 설정은 "기타"를 기준으로 나뉘었다. 그래서 "변수를 보고 싶다"는 목적 하나로 갈 곳이 3곳이었다.
   - 실제 피드백 1: "이미 변수가 있는데 '만들기'에 들어가 없다는 걸 확인한 뒤 '적용'으로 이동했다."
   - 실제 피드백 2: "무엇이 어디에 연결됐는지 알 수 없다."
   - 실제 피드백 3: "[변수]가 적용 탭 안에서 열리는 건가?"
2. **우회로가 계속 늘었다.** 기존 변수 배너 2개, 연결 카드 → 변수 관리 링크, 탭 이동 6곳은 모두 기준이 섞여서 생긴 문제를 덮는 패치였다.
3. **같은 데이터를 두 번 그렸다.** 연결 카드의 "연결 현황"과 변수 관리의 "사용처"는 같은 조회 함수(`scanBindings`)를 쓴다.
4. **노트북 화면을 너무 가렸다.** 13인치 노트북(1470×956으로 가정, 추정치)에서 400×660 창은 높이의 약 75%를 가린다. 400×510이면 약 58%, 최소화하면 약 5%다.

## 2. 원칙

1. **탭 = 다루는 대상.**
   - **변수 탭:** 파일의 변수를 보고 만든다. 선택한 레이어와 무관하게 의미가 있다.
   - **레이어 탭:** 지금 선택한 레이어를 고친다(변수 붙이기, 이름, 컴포넌트). 선택이 없으면 할 일이 없다.
   - **설정 탭:** 자주 안 바꾸는 값과 라이선스.
2. **보기는 변수 탭, 붙이는 작업은 레이어 탭.** 이미 연결된 상태는 변수 탭에서만 보여 준다.
3. **유료/무료는 탭이 아니라 버튼에서 표시한다.** 기준은 그대로다. 이미 있는 자산을 쓰는 일은 무료, 새로 만드는 일은 유료다.
4. **변수 관리 범위.** v2의 "플러그인은 변수 CRUD 앱이 아니다" 원칙은 2026-10 변수 관리 도입으로 이미 일부 번복됐다. v3 기준 범위는 다음과 같다.
   - 보기, 복사, 레이어 선택, 상세, 교체는 플러그인에서 한다.
   - 이름 변경은 v3 다음 별도 PR로 한다.
   - **삭제와 값 편집은 하지 않는다.** 둘 다 Figma Variables에 맡긴다.
5. **400×510 화면 규칙.**
   - 각 화면의 주 버튼(전체 실행, 미리보기, 연결, 만들기 등)은 스크롤하지 않아도 보인다.
   - 긴 목록(미리보기 트리, 변수 목록)은 목록 영역 안에서만 스크롤한다.
   - 페이지 전체 가로 스크롤은 0이다.

## 4. 화면별 상세

글자 와이어프레임은 폭 400, 높이 510 기준이다. 픽셀까지 똑같이 만드는 것이 목표가 아니라, 배치와 우선순위를 정하는 용도다.

### 4.1 공통 셸

```
┌────────────────────────────────────────┐
│ [ 변수 ]  레이어   설정              —  │  ← 탭 바 (sticky) · 오른쪽 끝 최소화
├────────────────────────────────────────┤
│ (레이어 탭에서만) ● 프레임 1 · 하위 42    │  ← 선택 표시줄
├────────────────────────────────────────┤
│                탭 내용                  │
└────────────────────────────────────────┘
```

- 탭은 3개이고, 키보드 화살표로 이동한다(기존 roving tabindex 유지).
- **없애는 것:** [변수] 버튼, "← 돌아가기", ↕ 높이 전환.
- **[—] 최소화:** 4.8을 본다.

### 4.2 변수 탭 — 시작 화면 (변수 0개)

```
┌────────────────────────────────────────┐
│ 이 파일에는 아직 변수가 없어요            │
│ ┌ 한 번에 정리 ───────────────────────┐ │
│ │ 선택한 화면의 색·간격을 변수로 만들고  │ │
│ │ 붙입니다                            │ │
│ │ ☑ 역할 매핑🔒 ☐ 다크🔒 ☐ 텍스트 스타일🔒│ │
│ │                       [ 전체 실행 ]  │ │
│ └─────────────────────────────────────┘ │
│ 준비 현황  G 0 · S 0 · C 0 · 텍스트 0     │
│ 하나씩 하려면  [ 색부터 만들기 → ]        │
└────────────────────────────────────────┘
```

- **보이는 조건:** 로컬 변수가 0개일 때만 보인다(`PREREQ_STATE`의 `tierVars + otherVars === 0`).
- 변수가 생기면 다음에 이 탭에 들어올 때 변수 목록으로 바뀐다. 실행 중에는 화면을 바꾸지 않는다.
- "다시 보지 않기"(온보딩 숨김)는 없앤다. 변수가 생기면 이 화면은 저절로 사라진다.
- 준비 현황은 카드 대신 한 줄로 줄인다(510 높이).

### 4.3 변수 탭 — 변수 목록 (기본)

```
┌────────────────────────────────────────┐
│ 연결 18 · 레이어 7        [+ 만들기] [⋯] │
│ (Global G)(Semantic S)(Brand ?)    ›   │  ← 컬렉션 칩
│ [선택에서 쓰는 것만 · 레이어 3 ▾]  🔍    │
│ 이름                값 Light ▾    사용   │  ← 모드가 2개 이상일 때만 ▾
│ ▾ color/primary               3        │  ← 그룹 머리 (누르면 접힘)
│    ■ 500           #3B82F6      12     │
│    ■ 600           #2563EB       3     │
│ ▸ color/neutral               8        │
│ ▸ spacing                     5        │
├────────────────────────────────────────┤
│ 상태 줄                                 │
└────────────────────────────────────────┘
```

- **머리줄**
  - "연결 N · 레이어 M"을 표시한다. N은 선택 안의 연결 수, M은 연결이 하나라도 있는 레이어 수다.
  - 둘 다 이미 있는 조회 결과(`BINDINGS_RESULT.total` / `boundNodes`, `forManager` 경로)로 셀 수 있다.
  - 선택이 없으면 "선택 없음"으로 표시한다.
- **컬렉션 칩**
  - 칩 하나가 컬렉션 하나다. 이름 옆에 역할 배지(G/S/C)를 붙이고, 역할이 없으면 "?"를 붙인다.
  - 칩이 넘치면 가로로 밀어서 본다. 이 가로 스크롤은 칩 줄 안에서만 생긴다.
  - 처음 고르는 칩은 기존 규칙(`pickInitialCollection`)을 따른다. 사용자가 고르기 전까지는 사용 데이터에 맞춰 다시 고른다.
  - 배지를 누르면 "컬렉션 역할 지정" 팝업이 열린다. 지금 설정 탭의 "컬렉션 계층" 카드 내용을 그대로 옮긴다.
- **범위**
  - 기본은 "선택에서 쓰는 것만"이다.
  - 이 탭에는 선택 표시줄이 없으므로, 선택 상태를 범위 컨트롤 안에 표시한다("레이어 3"). 선택이 없으면 "선택 없음 — 전체 보기"로 바뀐다.
- **목록**
  - 그룹 경로마다 머리 한 줄을 둔다. 그룹을 묶는 함수(`groupRows`)는 이미 있다.
  - 그룹을 중첩하거나 들여쓰지 않으므로 400 너비를 아낀다.
  - 범위가 "선택에서 쓰는 것만"일 때는 모두 펼친다. "전체"일 때는 그룹 수가 10개를 넘으면 모두 접는다.
  - 열은 이름(마지막 토막), 값, 사용 수 3개다.
  - 값 열은 모드 하나만 보여 준다. 모드가 2개 이상이면 열 머리의 ▾로 모드를 바꾼다.
  - 모든 모드 값을 한 번에 보려면 상세 팝업을 연다.
  - 별칭(다른 변수를 가리키는 값)은 기존처럼 알약 모양으로 표시하고, 색 견본은 별칭을 따라가 실제 색을 보여 준다.
- **우클릭/⋯ 메뉴:** 기존 6개(복사 3종, 레이어 선택, 상세, 교체)를 그대로 둔다. 이름 변경과 삭제는 보이지 않는다.
- **[⋯] 메뉴**
  - 컬렉션 역할 지정…
  - 코드로 내보내기…: 팝업 안에서 형식(W3C/CSS)과 폰트 단위(px/rem)를 고르고 [내보내기]를 누른다.
- **[+ 만들기]:** 만들기 하위 화면(4.4)으로 바로 이동한다.

### 4.4 변수 탭 — 만들기 (하위 화면)

```
┌────────────────────────────────────────┐
│ ← 변수 목록                              │
│ ▸ 한 번에 정리 (마법사)                   │  ← 접힘. 펼치면 4.2와 같은 카드
│ (1 색)─(2 토큰)─(3 테마)─(4 타이포)       │  ← 기존 단계 레일
├────────────────────────────────────────┤
│ (지금 만들기 탭의 각 단계 카드 그대로)      │
│                           [ 다음 → ]    │
└────────────────────────────────────────┘
```

- 지금 만들기 탭의 4단계 내용을 그대로 옮긴다. 카드, 미리보기, 잠금 모두 같다.
- 타이포 단계의 "기존만 연결" 버튼은 레이어 › 연결로 옮긴다(4.5).
- 마지막 단계에는 출구 두 개를 둔다: "변수 목록에서 보기", "레이어에 붙이기 →"(레이어 › 연결로 이동).
- 다크 단계의 "토큰 생성으로 →"는 같은 화면 안에서 단계를 이동하는 버튼이 된다.
- "← 변수 목록"으로 돌아오면 변수 목록을 다시 불러온다(`GET_VAR_TABLE`).

### 4.5 레이어 탭 — 연결

```
┌────────────────────────────────────────┐
│ ● 프레임 1 · 하위 42                     │
│ [ 연결 ]  이름   컴포넌트                 │
├────────────────────────────────────────┤
│ 변수 붙이기                 [ 미리보기 ]  │
│ ─ 미리보기 후 ─                          │
│ 후보 18 · 건너뜀 4                       │
│ [값이 다름 3] [잠김 1]                   │
│ ☑ Card     채움 색 → color/bg/surface   │
│   ☑ Title  글자 크기 → font/size/lg     │
│ ...                [ 선택한 항목에 연결 ] │
│ ─ 연결 후 ─                              │
│ ✓ 18개 연결 · 건너뜀 4  변수 탭에서 보기 ↗ │
├────────────────────────────────────────┤
│ 텍스트 스타일  같은 모양의 기존 스타일에 연결 │
│                     [ 기존 스타일 연결 ]  │
└────────────────────────────────────────┘
```

- **남는 것**
  - 미리보기, 후보 트리(체크박스), 선택한 항목에 연결
  - 진행률과 취소, 건너뛴 사유 칩
  - 레이어 머리를 누르면 캔버스에서 그 레이어를 선택하는 동작
- **없애는 것**
  - "연결 현황" 버튼과 자동 연결 현황 조회(선택이 바뀌면 250ms 뒤에 다시 조회하던 것)
  - 조회를 기다리는 동안 목록을 흐리게 하던 처리
  - 연결 현황 모드("=" 줄)와 연결 후 결과 트리
  - 보기 필터 줄(`#bindViewRow`), "변수 관리에서 보기" 버튼
- **연결 후:** 숫자 요약, 건너뛴 사유 칩, "변수 탭에서 보기 ↗"만 남긴다. 링크를 누르면 변수 탭이 "선택에서 쓰는 것만" 범위로 열린다.
- **텍스트 스타일 "기존 스타일 연결"**
  - 만들기 › 타이포에서 옮겨 온다. 스캔 표와 무관하게 동작하므로(`APPLY_TEXT_STYLES`) 옮겨도 기능은 같다.
  - 이번에 **무료로 바꾼다**(`code.ts`의 `requireTextStyles` 검사 제거, UI 잠금 해제).
  - 스캔과 등록(새 스타일 만들기)은 그대로 유료다.
- **선택이 없을 때:** "레이어를 선택하세요" 안내를 보이고 버튼을 비활성화한다.

### 4.6 레이어 탭 — 이름, 컴포넌트

- 지금 적용 탭의 두 단계를 그대로 옮긴다. 기능은 바뀌지 않는다.
- 레일을 하위 탭으로 바꾸므로 번호(①②③)와 "다음 →"를 없앤다. 세 작업은 순서가 없다.

### 4.7 설정 탭

```
┌────────────────────────────────────────┐
│ 기본값                                  │
│  기준 크기 [16]px   이름 정리 깊이 [8]    │
│  격자 [8]px         허용오차 [0.5]px     │
├────────────────────────────────────────┤
│ 라이선스                                 │
│  [키 입력            ] [검증] [해제]      │
│  [ 결제 · 구독 관리 ]                    │
└────────────────────────────────────────┘
```

- **나가는 것:** 컬렉션 계층(→ 변수 탭 팝업), 코드로 내보내기(→ 변수 탭 ⋯ 팝업)
- **카피 수정:** 기본값 안내 "만들기·적용 화면에는 안 보여요"를 "변수 만들기와 연결에 쓰는 값이에요"로 바꾼다.

### 4.8 최소화

```
펼친 상태                          최소화 상태 (400 × 48)
┌──────────────────────┐          ┌──────────────────────┐
│ [변수] 레이어 설정  — │   [—] →  │ [DSL]                │  ← 바 어디를 눌러도 펼침
│ …                    │   ← 클릭  └──────────────────────┘
└──────────────────────┘
```

- **최소화 상태 화면:** "DSL" 글자 마크만 보인다.
  - 플러그인 이름과 닫기 버튼은 피그마가 창 위에 붙여 주는 머리줄에 이미 있다.
  - 로고 파일이 생기면 글자 마크를 로고로 바꾼다(커뮤니티 에셋 파일의 `icon-128` 프레임).
- **글자 마크:** "DSL" 굵은 글씨를 둥근 사각형 배지에 넣는다. 색은 플러그인 강조색이고, 다크 테마에서도 읽혀야 한다.
- **동작**
  - 바를 누르거나 Enter/Space를 누르면 510으로 펼쳐진다. 보던 탭과 스크롤 위치는 유지한다.
  - 마우스를 올리면 툴팁 "펼치기"가 뜬다. 접근성 이름도 "펼치기"다.
- **다시 열 때:** 최소화 상태는 **기억하지 않는다.** 플러그인을 다시 열면 항상 400×510이다.
- **작업 중 최소화:** 실행 중이던 작업(미리보기, 연결, 마법사)은 계속 돈다. 펼치면 결과가 보인다.
- **크기를 400×48로 정한 이유:**
  - 펼칠 때 창 위치와 너비가 바뀌지 않는다.
  - 더 작은 정사각형은 피그마의 최소 창 크기와 창 위치 변화를 확인하지 않아서 쓰지 않는다.

**A. 처음 쓰는 파일 (변수 0)**

## 10. 자동 검사(`verify:bind`) 변경 계획

지금 있는 36개 항목을 v3에 맞게 바꾼다.

| 지금 항목(스크립트 그룹 번호) | 처리 |
|---|---|
| 4 전제 경고 · 6 시작 시 GET_PREREQ 1회 | 유지 (레이어 › 연결에서) |
| 3 연결 현황 debounce · 표시 · 흐림 · 흐림 해제 (4개) | **삭제** (기능이 없어짐) |
| 2 늦은 연결 현황이 미리보기를 덮지 않음 | **삭제**. 이전 선택의 미리보기를 버리는 검사(2-b)는 유지 |
| 1 미리보기 · 후보 · 체크박스 | 유지 |
| 5 미리보기 중 선택 변경 | 유지 |
| 8 "=" 줄 · 취소선 · 디자인 말 레이블 · 좌우 여백 한 줄 | "=" 줄은 삭제. 나머지는 미리보기("→") 줄 기준으로 유지 |
| 8 "→" 미리보기 줄 · 레이어 머리 선택 | 유지 |
| 9 [변수] → 넓은 창 · 돌아가기 → 400 | **삭제** |
| 9 관리 조회 forManager · 쓰는 것만 · 모드 열 · 메뉴 · Esc · 상세 | 변수 탭 기준으로 유지. "모드 열"은 "값 열 머리 모드 선택"으로 바꿈 |
| 7 좁은 폭 "다음 →" · 가로 스크롤 | 400 기준 유지 |
| 9 360/400 탭 바 | 유지 (탭 3개 + 최소화 버튼) |
| 9 시작 시 스크립트 오류 0 | 유지 |

**새로 넣을 항목**
- 처음 열면 변수 탭이 활성이다.
- 시작할 때 `SET_UI_SIZE`가 400×510을 요청하고, 탭을 바꿔도 크기 요청은 0회다.
- 변수 0개면 시작 화면, 1개 이상이면 변수 목록이 보인다.
- 선택 표시줄은 레이어 탭에서만 보인다.
- 510 높이에서 각 탭의 주 버튼이 스크롤 없이 보인다(변수: + 만들기 / 시작 화면: 전체 실행 / 레이어 › 연결: 미리보기 / 설정: 검증).
- 컬렉션 칩을 누르면 목록이 바뀌고, 그룹 머리를 누르면 접힌다.
- 모드가 1개인 컬렉션에서는 값 열 머리에 ▾가 없다.
- 머리줄에 "연결 N · 레이어 M"이 보인다.
- 메뉴에 이름 변경과 삭제가 없다.
- 연결 후 "변수 탭에서 보기"를 누르면 변수 탭이 "선택에서 쓰는 것만"으로 열린다.
- 설정 탭에 컬렉션 계층과 내보내기가 없고, ⋯ 메뉴에서 두 팝업이 열린다.
- 선택을 바꿔도 관리용이 아닌 `SCAN_BINDINGS` 요청이 0회다.
- 최소화하면 `SET_UI_SIZE`가 `mini`를 요청하고 "DSL" 마크만 보인다. 바를 누르면 510으로 돌아가고 보던 탭이 유지된다. `mini`는 저장되지 않는다.
- 기존 텍스트 스타일 연결 버튼은 Free 티어에서도 잠기지 않는다.
